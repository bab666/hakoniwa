# 常識改変：電車（train）の設計（2026-11-04 担当TR）

R18版だけの無料アップデートの箱庭。既存の「常識改変」（kaihen）の姉妹の部屋で、舞台を満員電車に移した。

## 1. 世界観

- 満員電車で乗客どうしが体を寄せ合い、慰め合うのが「当たり前のマナー」になった世界。駅のポスター・車内放送・駅員までがそのマナーを促す。
- 誰も困っておらず、誰も咎められない。乗客は「今日は混んでますね」と会釈してから当然のように触れる。住人も最初はその常識の中にいる。
- 見どころは「流され続けるか、違和感に気づいて催眠のような常識が覚めるか」。覚めたら、通報する・降りる・分かったうえでスリルを楽しむ・言い出せない、に分かれる。
- 現実の性犯罪を描く話ではないので、「被害」「犯人」「襲う」「無理やり」「逃げる」「助けを求める」の語と筋は使わない。合意のない展開（force）の印は付けない。
  覚めたあとの性的な場面は、本人が分かったうえで選んだとき（スリル）だけ。言い出せない人には、乗客のほうが手を引く（「反応のない相手にはそれ以上しないのも、この路線のマナー」）。
- 登場人物はすべて成人。R18 が中心の箱庭（`HK.State.R18_CORE.train`。R18に参加しない は効かせない、性行為の相手の固定は効かせる）。

## 4. 数値と判定の式

住人ごとに かかり具合 imm・違和感 doubt・快楽 plea・理性 reason（0〜100）を持つ（メーターに出る）。

- 理性の初期値：`55 + A×1.1 + CP×0.9`（40〜100。エゴグラムは 0〜20。SoloKit と同じ式）。
- かかり具合の初期値：`常識の強さ(55/68/76) + AC×14 − A×10 + (心の強さの係数 willK − 1)×25`（willK：弱い 1.3・ふつう 1・強い 0.7）。
- 触れ合い一駅ぶんの快楽：`(最初の駅 10／深まる 20) × 感じやすさ × 性欲の倍率(HK.Pos.libK) × 混み具合 × 乱数0.8〜1.2`。理性は快楽の 1/4 下がる。
- 違和感の伸び（一駅ごと）：`(0.35 + A×0.9 + CP×0.35 − AC×0.2) × 常識の強さ × (2 − willK) × 乱数5〜10 × (1 − 快楽/220)`（A・CP・AC は 0〜1 の気質）。
  触れ合いの外の人・性欲「なし」の人は ×1.4、行動「戸惑う」「口に出す」は ×1.2、6% の確率でふとした気づき（×3。素直な人にも起きる、らしくない気づき）。かかり具合は違和感の伸びの 0.3 倍下がる。
- **もやもや（これってえっちなお触り？）**：違和感 30 以上で一日一回。乗客の「マナーですよ」に騙される確率 `0.35 + かかり具合/200 + AC×0.3 + NP×0.1 − A×0.35 − 慎重さ×0.2`（0.08〜0.9）。騙されると違和感 −12・かかり具合 ＋6（マッサージの「言い訳に騙される」と同じ手触り）。騙されなければ「違和感」の段階へ。
- **覚める**：違和感 55 以上で毎駅 `(違和感 + 理性×0.3 − かかり具合×0.5 − 快楽×0.25) / 100`（0.04〜0.9）。覚めるとかかり具合 −35・理性 ＋15。
- **かかり直し（翌朝）**：`快楽の最高/100×0.55 + かかり具合/100×0.3 + (willK−1)×0.8 − A×0.25 + 常識の強さ − (通報して駅員が応じた 0.3) − (覚めた回数−1)×0.12 − (スリル 0.1)`（0.02〜0.8）。引き戻されると、かかり具合 ＋30・違和感 −40。
- **覚めたあとの分岐**（重みのくじ。らしくない動きも残る）：
  - 通報：`0.25 + CP×1.2 + A×0.4 + 理性/250 + (厳格・丁寧・強気 0.4) + (連れがいる 0.3) + (ゆるい 0.25) − 快楽/130 − AC×0.3`
  - 降りる：`0.35 + 慎重さ×0.8 + AC×0.3 + (内気・健気・穏やか 0.35)`
  - スリル：`0.08 + FC×0.9 + 衝動性×0.5 + 快楽/90 + (奔放・強気 0.35)`（乗客との触れ合いに出られて、性欲「なし」でない人だけ）
  - 言い出せない：`0.15 + AC×0.9 + (内気・意地っ張り・健気 0.45) + (1 − 理性/100)×0.4`

## 5. 一日の流れ

乗車（路線・ポスター・混み具合）→ 一駅ごとの触れ合い（最初の駅＝触れ合い、二駅目から＝深まる。違和感の判定）→ 終点直前の満員車両（山場）→ 駅での後味。
記録を読みやすくするため、1〜2 日目は乗車の最初と深まりを二度まで、3 日目からは「いつもの車両」の一件にまとめる（数値は毎駅動く）。

- 山場：快楽が閾値（長さと混み具合で 28〜60）を超え、覚めていない（またはスリルを選んだ）人。
  - 一回目は長い場面（`HK.ThickSex`／男性向けは `HK.ThickEro`）。`HK.Play.addScene('train', { id: 'train-car' })` で、車内の段（人の壁・扉と手すり・揺れ・終点の放送）と立ったまま（tachi）・着衣（chakui）を差す。
  - 二・三回目は小説調なら車内だけで組んだ中くらいの場面（3 組 × 2 本）、男性向けなら長い場面。四回目からは「終点前」の短い一文（場面は描かない）。
  - 周りの乗客が加わる段（髪を撫でる・背中を支える）と、住人の態度 9 種の一文（受け・攻めで別）を山場のあとに足す。
- 乗客（モブ）：`HK.Mob.make`（役割つきの名前。性別は住人の体の関係の相手・恋愛対象に合わせる）。声は `HK.Moan.mob`。
- 体の組：攻めの体で mf（男性の体の攻め）／ff（女性どうし）／fm（女性の攻め×男性）。触れ合い・深まり・攻めの側・中くらいの場面・長い場面の車内の段は 3 組すべてに専用文。性器なしの人は胸・尻・股間だけの文か長い場面の NoGen。
