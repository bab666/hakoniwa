# 血縁の二人を「友人」にしない・話題の出来事の共通の上限（2026-11-04）

利用者の指示（不具合リスト 1104 の追加の指示）：
- 「親子とか血縁で目立つのだが、関係が友人になったり、友人表現の台詞が出たりしがちだ。親子は親子だから、『○○な親子』とかって表現すべき。関係図とかでも。他の血縁とかも同様だ」
- 同居生活で、住人に設定した話題の単独行動の出来事が、関係の制限で生活の出来事が弾かれると穴埋めになって 7 割を占めた。同居・新婚・看病は部屋ごとに上限を入れたので、本体の topics.js にも共通の上限を入れる。

## 1. 血縁の二人

### 決まり
- 対象：家族の関係（`HK.TIES` の `family`）＝親子・擬似親子・兄弟姉妹・兄弟（庇護／親友のよう／不仲）・双子・義理の兄弟・親族。主の関係でも重ねた関係でも。
- 語（`HK.Kin.word`）：親子・擬似親子・親戚。きょうだいは性別と年齢で「姉弟」「兄妹」「姉妹」「兄弟」「双子の兄妹」「義理の姉弟」など（sib-word.js の `HK.Sib.pairWord`）。
- 結末の関係の名前（`HK.Kin.name`）：様子＋語。
  - 家族の絆・友人 →「仲の良い〜」／相棒 →「支え合う〜」／確執・嫌悪・宿敵 →「確執のある〜」「反目し合う〜」「いがみ合う〜」／気まずい →「ぎくしゃくした〜」／他人のまま →「よそよそしい〜」／庇護と依存 →「守り守られる〜」／共犯 →「秘密を分け合う〜」／親族として支え合う →「支え合う〜」
  - 恋愛へ進んだ二人（「恋愛：あり」の家族）：恋人 →「恋人になった〜」、両片想い →「両片想いの〜」、片想い →「片想いを抱えた〜」、愛憎 →「憎みながら惹かれ合う〜」。そのほかは「名前（語）」（「破局（兄妹）」「同棲中の恋人（親戚）」）。箱庭の名前がもう血縁を言っていればそのまま。
  - 名前に「友人・友達・親友」を含む結末は「家族の絆」（kinbond）に寄せて「仲の良い〜」にする。
- 結末の文：「親子として、互いを支え合う形に落ち着いた。」「姉妹だからこそ、こじれた溝が埋まらなかった。」のように語を入れる。
- 関係図：最終は結末の名前。開始時は関係の設定（「親子」「姉弟（庇護）」。利用者が選んだ「兄弟（親友のよう）」はそのまま）、関係の設定が無い組・転機は数値から決めた札に同じ言い換えを当てる（view-map.js の `kinLab`。古い結果は関係の設定から語を引く）。
- 本文：血縁の二人に、二人を友人として扱う文（「友人どうし」「友達のふり」「友達のままがいい」「親友・相棒」「親友の{b}と再会」など）を出さない。第三者の友人（「友達に会う」「友人の声」など）はそのまま。

## 2. 話題の出来事の共通の上限（topics.js）

## 3. 関係の種類の名前を本文に出さない（2026-11-05）

利用者の指摘：「同居や新婚などで擬似親子や義兄弟などと表示されると思うが、本人たちが自称していると変。『擬似』はとっても良い。せめて『血は繋がっていないものの』とかの表現にすべき」。

### 決まり
- 関係図の札・設定の選択肢の名前（擬似親子・疑似親子・義兄弟・義姉妹・義理のきょうだい・親代わり・拾った／拾われた関係・セフレ・友達以上恋人未満・宿敵・両片想い）は、**本人の台詞と本人の視点の地の文に出さない**。結末の関係の名前・関係図・結果欄・設定の説明・表示名（label）・理由の欄はこれまでどおり。
- 「元恋人」は地の文では普通の言い方なので残す（台詞では「昔付き合っていた相手」「昔の恋人」、本人が自分を呼ぶ「元恋人の自分」は「別れた自分」）。「義理の姉弟」「義理の兄」のように続柄がはっきりした言い方は自然なので残す（性別・上下が決まらない「義理のきょうだい」だけ避ける）。
- 本文の言い方は `HK.Kin`（engine.js）に足した関数で選ぶ（配役の名前で始まりを決めて順に回す。乱数は引かない）：
  - `HK.Kin.say(o, t, A, B, kind)`：家族。地の文（既定）は擬似親子 →「血の繋がらない親子」「育ての親と子」「血縁のない親子」、義理のきょうだい →「義理の姉弟」「親の再婚で家族になった姉弟」「あとから家族になった姉弟」。台詞（`'say'`）は「親子」「姉弟」。`HK.Kin.ofSay(ctx, a, b, kind)` は二人から引く。
  - `HK.Kin.rel(o, t, A, B, kind)`：どの関係でも。セフレ →「体だけの相手」「割り切った関係の相手」「体だけのつき合いの相手」、元恋人 →「かつての恋人」「一度は別れた恋人」「昔の恋人」、友達以上恋人未満 →「友達とも恋人ともつかない相手」「友達より少しだけ近い相手」「恋人の一歩手前の相手」、敵対 →「犬猿の仲の相手」など。括弧つきの名前は括弧を外す。
  - `HK.Kin.role(t, side)`：擬似親子の roleA「親代わり」→「親」（台詞・地の文の {ra}）。台詞の「私は、あなたの○○だ」は「育ての親」。
- 例：「これからも、擬似親子としてよろしく」→「これからも、親子としてよろしく」／「{a}と{b}は擬似親子だった」→「{a}と{b}は血の繋がらない親子だった」（電車）／「親代わりとしてではなく」→「育ての親としてではなく、一人の人として」／「セフレに優しくしすぎ」→「体だけの相手に、優しくしすぎ」／「元恋人と閉じ込められるとか」→「昔付き合ってた相手と閉じ込められるとか」／新婚の告白「擬似親子としてじゃなくて」→「親子としてじゃなくて」。
