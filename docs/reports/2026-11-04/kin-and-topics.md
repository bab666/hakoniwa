# 血縁の二人を「友人」にしない・話題の出来事の共通の上限（2026-11-04）

利用者の指示（不具合リスト 1104 の追加の指示）：
- 「親子とか血縁で目立つのだが、関係が友人になったり、友人表現の台詞が出たりしがちだ。親子は親子だから、『○○な親子』とかって表現すべき。関係図とかでも。他の血縁とかも同様だ」
- 同居生活で、住人に設定した話題の単独行動の出来事が、関係の制限で生活の出来事が弾かれると穴埋めになって 7 割を占めた。同居・新婚・看病は部屋ごとに上限を入れたので、本体の topics.js にも共通の上限を入れる。

## 1. 血縁の二人

### 決まり
- 対象：家族の関係（`HK.TIES` の `family`）＝親子・擬似親子・兄弟姉妹・兄弟（庇護／親友のよう／不仲）・双子・義理の兄弟・親族。主の関係でも重ねた関係でも。
- 語（`HK.Kin.word`）：親子・擬似親子・親戚。きょうだいは性別と年齢で「姉弟」「兄妹」「姉妹」「兄弟」「双子の兄妹」「義理の姉弟」など（sib-word.js の `HK.Sib.pairWord`）。
- 結末の関係の名前（`HK.Kin.name`）：様子＋語。
  - 家族の絆・友人 →「仲の良い〜」／相棒 →「支え合う〜」／確執・嫌悪・宿敵 →「確執のある〜」「反目し合う〜」「いがみ合う〜」／気まずい →「ぎくしゃくした〜」／他人のまま →「よそよそしい〜」／庇護と依存 →「守り守られる〜」／共犯 →「秘密を分け合う〜」／親族として支え合う →「支え合う〜」
  - 恋愛へ進んだ二人（「恋愛：あり」の家族）：恋人 →「恋人になった〜」、両片想い →「両片想いの〜」、片想い →「片想いを抱えた〜」、愛憎 →「憎みながら惹かれ合う〜」。そのほかは「名前（語）」（「破局（兄妹）」「同棲中の恋人（親戚）」）。箱庭の名前がもう血縁を言っていればそのまま。
  - 名前に「友人・友達・親友」を含む結末は「家族の絆」（kinbond）に寄せて「仲の良い〜」にする。
- 結末の文：「親子として、互いを支え合う形に落ち着いた。」「姉妹だからこそ、こじれた溝が埋まらなかった。」のように語を入れる。
- 関係図：最終は結末の名前。開始時は関係の設定（「親子」「姉弟（庇護）」。利用者が選んだ「兄弟（親友のよう）」はそのまま）、関係の設定が無い組・転機は数値から決めた札に同じ言い換えを当てる（view-map.js の `kinLab`。古い結果は関係の設定から語を引く）。
- 本文：血縁の二人に、二人を友人として扱う文（「友人どうし」「友達のふり」「友達のままがいい」「親友・相棒」「親友の{b}と再会」など）を出さない。第三者の友人（「友達に会う」「友人の声」など）はそのまま。

## 2. 話題の出来事の共通の上限（topics.js）

### 決まり
- 一回の遊びで、話題の記録（話題の出来事 tp_*・雑談に添える一文・物語型のひと言）は出来事の **12%** まで（`T.CAP.share`。始まってすぐの 1 件は許す）。
- 一区切り（エンジン型は `stepIndex`、物語型は区切りの見出し）に **1 件**まで（`T.CAP.perDay`）。
- 同じ語は**二区切り続けて**出さない（`T.wordOk`。`T.pick` が前の区切りの語を候補から外す）。
- 箱庭ごとの上書きの口：箱庭の `topicCap: { share, perDay }`、日の単位は `topicDay(x)`（今は使っている箱庭なし）。
- 話題の無い回は何も数えず、乱数も引かない（今までの結果と同じ）。同居生活（futari）・看病（set-b）の部屋ごとの上限はそのまま重なる。
