# 二人きりの部屋の「第三者がいないと成り立たない文」（pair-only）

2026-11-04　担当PR（work/pair2）。

利用者の報告：「出られない部屋で二人きりの場合でも、相手以外の誰かに話しかける・笑いかけるなどの地の文や、執着キャラが『誰に話しかけたのか』と相手に聞くなどの矛盾がある。第三者がいないと成り立たない会話に違和感がある」

**結論**：出られない部屋を参加 2 人で回して記録の文を拾う点検 `hakoniwa-tools/tone-check/pair-only-audit.js` を作り、拾った出来事・文を直した。出られない部屋の 2 人（R18版・全年齢モード、各 1,200 回）で、直す前 1,764 件 → 直したあと **0 件**。点検は audit-all の追加の配役パス `--extra=pair` にもして、check.js が出られない部屋・執着・関係・小イベント・共通の出来事などの js を変えたときに回す（合格は「出られない部屋の 2 人で 0 件」）。

## 1. 点検（`pair-only-audit.js`）

```

node hakoniwa-tools/tone-check/audit-all.js --only-extra --extra=pair --modes=r18,safe   # check.js が回すのと同じ（出られない部屋 × 400 回 × 2 通り）
```

- 配役：参加 2 人。男×女・男×男・女×女を順に、恋愛対象はたがいに合わせる。受け攻め（攻め×受け・受け×攻め・リバ×リバ・未設定）、口調（3 回に 1 回は全口調を順に）、関係（なし・恋人・片想い・執着の 6 型・元恋人・体だけ・友人・敵対・ライバル・本命・夫婦・幼馴染・不仲・崇拝・恐怖・DV・両片想い）、箱庭の設定（条件・濃さ・作風・全員で出られる・三人の場面でだけ数える…。濃さは 2 回に 1 回「濃い」）を回ごとに回す。4 回に 1 回は「登場しない住人の名前を出す」を入にして、入力に登場しない住人（友人・家族）を渡す。

## 3. 直し方

共通の仕組み（engine.js）：

- `ctx.noThird()`・`HK.noThird(ctx)`：ほかに誰もいない箱庭（箱庭の定義に `closed: true`。出られない部屋・無人島）で、場にいる人が二人以下。
- `HK.THIRD_RE`：第三者を前提にした言い回し。`ctx.pick` は、もとから二人以下のとき「皆・全員・誰か…」の文を避けていた（GROUP_RE）が、それに加えて `noThird` のとき `THIRD_RE` の文も避ける（候補を絞るだけで、乱数の引き方は変えない。全部当たるときは元のまま）。
- `HK.pairOnly(ctx, 候補)`：個別の部品が候補を絞るのに使う。

| 直し方 | 件数 | 出来事・文（ファイル） |
|---|---|---|
| (a) 3 人以上のときだけ出す | 4 | エッチのきっかけ「誰か一組でも…全員で外へ」（sex-lead-r18.js。場にいる人が 3 人以上のときだけ）／扉の紙の「ほかの全員も出られる」（scenario-room.js の `HK.roomLabelOf` に人数を渡し、2 人なら添えない。room-games.js も）／かばう「誰かが陰口を言いかけたとき」（hate-kit.js の friendGap。二人きりでは誘うほうに）／幼馴染の「ほかの誰かを気にしている」（room-tie-more2.js。`[大勢]` の札） |
| (b) 2 人用の言い換え・二人でも成り立つ文に | 11 | 執着（obsess-kit.js。二人きりでは第三者の文を外し、`O.TWO` の「今、何を考えてた？」「私以外のこと、考えてたでしょう」「どこを見てるの」「ここには、私たちしかいないよ」などを足す：seed・bind・purge・devote2・bind2・hatelove2）／取り残された人の結末（room-left.js。外に出た人がいない回は「出ていった人たち」「みんな」の文を外し、一人なら名前に、残った人が二人なら「残った人たち」「隣の人」を相手の名前に）／脱出の行く末「〇〇と二人で部屋を出た」・見出し「二人そろって部屋を出た」「二人とも…」「二人で脱出」（scenario-room.js・endings.js）／出たあとの情景 2 文（room-end.js）／きっかけ「もう言われなくても分かっていた」（sex-lead-r18.js）／不仲の無視の台詞 2 本（sib-feud.js：「話しかけないで。用件があっても聞かない」「あーあ、せっかくの気分が台無し」）／敵視の「{b}に背を向けた」（hate-kit.js）／媚薬・杯の「皆の顔」「みんなの分」、抜け駆けの「{b}が寝静まるのを待って」（scenario-room.js） |

ほかの箱庭（参考の点検で明らかだったもの）：

- 無人島：`closed: true`（上の共通の仕組みが効く）。料理の感想「全員が無言でおかわり」（island-cook.js）、獣に負けた「全員で引きずるように」（island-hazard.js）、船・自分用のイカダの「全員」「皆が眠ったあと」（island-escape.js）を二人のときは避ける。結末の見出し「二人とも生きて島を出た」（endings.js）。
- 宇宙船漂流記：`closed: true`。物語型の文の選び方（solo-story-kit.js の `ST.two`・`ST.pick`、ship.js の pk）で、生きている人が二人以下のとき「全員・皆・一人ずつ・当番…」の文を避ける。候補の無い危機の文 3 本（放射線の嵐・感染症）を二人でも成り立つ文に（ship-text.js）。
- ゾンビの街：「うつむく仲間の肩を一人ずつ叩いて回った」→「黙って叩いた」（zombie-events.js）。

## 5. 点検の工程（check.js）

- 依存の表（`check/table.js`）に印 `pair` を足した：出られない部屋の部品（scenario-room・room-*）・小イベント（mini*）・執着（obsess*）・関係（ties・tie-*）・共通（common・engine・endings）・不仲（hate-kit・sib-feud）・fwbcrush・solo-room-jealous・sex-lead・cold-fear の js を変えたとき、または変えた行に第三者の言い回し（ほかの誰か・みんな・全員・人目・誰と話…）があるとき。`pair` → audit-all の `--extra=pair`。`--all` にも入る。
- audit-all の追加の配役パス `pair`（R18版・全年齢モード、出られない部屋 × 400 回。HK_ONLY_SCEN で出られない部屋を外したときは回さない。パックの点検には入れない）。
- ついでに直した不具合：check.js が index.html の目録（scripts:begin〜end）の書き換えを「画面の変更」と見ていた（印の行が `<!-- scripts:begin（…） -->` なのに、`<!-- scripts:begin -->` だけを探していた）。そのため js を変えて build すると毎回 regress（結果の指紋の一致）が回り、結果の変わる変更では一致せず落ちていた。印の行の後ろに説明があっても合うようにした（build の入力のハッシュも同じ）。

- 新しい配役（二人きりのパス）で見つかった文の崩れ（misc P1）：箱庭の関係の場面「想う相手をじっと見つめる」の自由な人の一言「えへへ、なんでもない！…」が、一部の口調で「……、なんでもない。」に崩れていたので、間投詞を外した（trap-open.js）。

## 7. 残った誤検出・課題

- 点検は文の言い回しで拾うので、二人でも成り立つ言い方を除く表（EXCL）を足しながら使う。新しい誤検出は `--why` の「文ごと」で見て、除く表に足すか、文を直す。
- 宇宙船漂流記・ゾンビの街・ダンジョンRPG・吹雪の館の二人の回には、二人では大げさな「全員」「皆」が残る（第三者を前提にした矛盾ではないものが多い）。
- 出られない部屋の 3 人以上の回で、途中で二人だけになったとき（脱出・死亡）も `noThird` は効くが、点検は配役が 2 人の回だけを見ている。
