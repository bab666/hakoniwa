# 追加の感情・関係性の設計案（2026-10-25）

利用者の要望：感情 6 種（執着（依存）・無関心・憎悪・恐怖・負い目・執着（愛憎））と、関係 4 種（推し・許嫁・愛人・仲間）。
あわせて「強い感情を向ける人は、相手との感情の差（ギャップ）を感じると過激な行動を取りやすく」。

## 既存との重なり（どれを足し、どれを統合するか）

| 要望 | 近い既存 | 提案 |
|---|---|---|
| 執着（依存） | 執着（ヤンデレ）の4型のうち「依存」（気質で自動） | **執着の型を選べるようにする**（おまかせ／献身／束縛／排除／依存／愛憎）。新しい関係は増やさない |
| 執着（愛憎） | 探偵どうしの「愛憎」、執着の「排除」型 | **執着の型「愛憎」として追加**（探す・守る出来事と、苦しめる出来事の両方が出る） |
| 無関心 | 想われる側「興味がない」（恋愛だけ） | **新規「無関心」**（向きあり）。向けた相手への好意・信頼・惹かれ・緊張が初期値から一切動かず、その相手との恋愛・夜・嫉妬・心配の出来事に入らない |
| 憎悪 | 敵対（一方向の敵視＋度合い） | **敵対の度合いの最上位「憎悪」として追加**（貶める・陥れる・孤立させる出来事。死のある箱庭では危害に至りうる）。新しい関係にはしない |
| 恐怖 | 主従の「怯えている」、執着される側の「怖がっている」 | **新規「恐怖」**（向きあり）。避ける（同じ場所にいない・目を合わせない）、命じられると従う、庇護を求めて第三者に寄る、という行動を出す。恋愛・夜にはならない |
| 負い目 | 恩人（恩を返す） | **恩人に「気持ち」を付ける**：感謝（今のまま）／負い目（逆らえない・頼みを断れない・罪悪感の一文）。新しい関係にはしない |
| 推し | 一方的な好意・敬愛 | **一方的な好意・敬愛に「様子」を付ける**：敬愛（今のまま）／推し（ファン目線：応援する・グッズ・遠くから見守る・話しかけられて固まる）。恋愛にはならない |
| 許嫁 | 恋人・夫婦・本命 | **新規「許嫁」**（向きなし）。気持ちを選べる：乗り気／戸惑い／断りたい。恋愛・夜は許される。断りたい側がほかの人を好きになると「破談」の出来事。両方乗り気なら恋人と同じ扱い |
| 愛人 | セフレ・浮気・本命 | **セフレに「様子」を付ける**：対等（今のまま）／愛人（片方にほかの本命・夫婦がいる前提。秘密にする・ばれる・手切れの出来事）。新しい関係にはしない |
| 仲間 | バディ・同僚・友人・グループ | **足さない方がよい**。「同じ目的の集まり」はグループ機能＋同僚／バディで表せる。どうしても欲しければ「バディ」の弱い版（信頼だけ上がる）として別名にする |

結果：新しい関係は **無関心・恐怖・許嫁** の 3 つ。執着・敵対・恩人・敬愛・セフレは「型／度合い／気持ち／様子」の選択肢で広げる。

## 感情のギャップで過激になる仕組み（共通）
- 対象：執着（全型）・本命・盲信・恐怖（向ける側）・憎悪。
- ギャップ＝自分の想いの強さ − 相手から自分への好意（または、相手がほかの人に向けている好意）。
- ギャップが大きいほど、過激な枝（監禁・刃傷・貶め・暴走・従属の強要）の重みを上げる。「展開の重さ」が穏やかなら上限を抑え、重いなら上げる。
- 記録の理由書きに「想いの差：大（自分 80／相手 20）」のように出す。
- 既存の執着の段階（尽くす→束縛→暴走）はそのまま。ギャップは段階の進みを早める。

## 置き場所（実装のあたり）
- 定義：`ties.js`（TIES・TIE_ORDER・TIE_GROUPS・まとめて読み込みの別名・選択肢の「気持ち／様子／型」は既存の `feel`・`cold`・`grade` の仕組みに合わせる）。
- 行動：エンジン型は `engine.js` の mod()（無関心の凍結）・`romanceOk`・`HK.canLove`、恐怖の回避は `HK.State.here`／出来事の重みで。物語型は各箱庭の関係の出来事（`rel-*.js`・`tie-*.js`）に枝を足す。
- 過激化：`obsess-kit.js`（執着の段階）と `feud-kit.js`（敵対）に「ギャップ」を足し、`HK.Dark` の重さと掛け合わせる。
- 点検：orient／pos／state に加えて、無関心（値が動かない）・恐怖（恋愛・夜にならない）・許嫁（破談の整合）の点検を state-audit に足す。

## 決定（2026-10-25 利用者の返答）
- 上の統合案で進める（新規の関係は 無関心・恐怖・許嫁。憎悪は敵対の度合い、負い目は恩人の気持ち、推しは敬愛の様子、愛人はセフレの様子、執着の型は選べるように）。
- 仲間：関係としては足さず、**グループごとに「このグループを仲間とみなす」をオン／オフ**できるようにする。オンのグループの住人どうしは「仲間」（信頼が上がりやすく、助け合い・庇う・弔うの出来事が出る。恋愛・嫉妬には関わらない）として扱い、関係図にも「仲間」の線を薄く出す。
