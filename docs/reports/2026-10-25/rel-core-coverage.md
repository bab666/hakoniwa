# 「関係が中心」の箱庭で、設定した関係がその箱庭らしい場面に出るか（調査と追加）

対象：`scen-tags.js` の `relCore` の箱庭のうち合コン以外（クラスメイト・無人島・ふたりの日常・ゾンビの街・出られない部屋・オメガバース・バトルロワイヤル・裁判デスゲーム）。
追加は `js/rel-core-extra.js`（両ビルドに同じもの。`_order.txt` の `js/rel-group.js` の直後）。

**親子・きょうだい（ふつう）・友人・幼馴染・元恋人には、どの箱庭にも共通の場面がなかった**（行動の倍率だけ）。

## 2. 実測

関係を付けた6人（3つの配役：①同級生・親子・きょうだい・上司と部下・友人・元恋人、②幼馴染・師弟・恋人・片想い・セフレ・許嫁、③元恋人・きょうだい・親子・先輩後輩・同僚・同級生）で各箱庭を R18版（BR・裁判は全年齢版）で 12回×3配役＝36回。ふたりの日常は3人なので、二組の関係を回ごとに入れ替えた。
「関係に触れた」＝関係のある二人が出る出来事で、理由書きに関係の表示名・役割名があるか、本文・理由にその関係らしい語がある。
数字は「箱庭らしい場面（箱庭の出来事・箱庭の進行の文・今回の追加）／共通の出来事」。測り方は調査用のスクリプト（リポジトリの外。`HK.Ctx.prototype.say` を包んで出来事の id を記録し、箱庭の出来事・共通の出来事・追加に分けて数えた）。

## 3. 足したもの

- 場面 115（関係 5〜8種×2場面、ゾンビの親子は3場面）＋クラスメイトの担任の場面 4、候補の文 357＋12。台詞は3本・一人称「私」・二人称「あなた」。
- どの箱庭も、すれ違い系（からかい・気まずさ・葛藤）と仲良し系（気遣い・支え合い）が場面数で半々（クラスメイト 8:8、無人島 8:8、ゾンビ 5:6、ふたり 8:8、BR 8:8、裁判 8:8、部屋 6:6、オメガ 6:6）。
- 恋愛の出来事にはしない（元恋人も気まずさと友人としての気遣いまで）。性的な文はない。家族は恋愛の流れにしない。
- id は `tie_rc_` で始まり、全体の設定「関係性イベント：出さない」で外れる。理由書きは HK.TIES の表示名・役割名から作る（例「ユキノとカオルは親子（ユキノが親）：担任が親（すれ違い）」）。

## 4. 残り（薄いまま・提案）

- 無人島の同級生・友人・幼馴染、裁判の友人・幼馴染・師弟は、二人が関わる出来事そのものが少ない（関係の引き寄せ pull が小さい）ので、追加後も 12回で 2件前後。必要なら ties.js の pull ではなく、この箱庭だけ rel-core-extra.js の重み（D[箱庭].w・場面の w）を上げる。
- 合コンは別の担当で直した。宇宙船・邪神村などの「関係は一部」の箱庭は対象外。
