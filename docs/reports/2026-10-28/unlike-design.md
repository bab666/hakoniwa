# 「らしくない」行動の設計（運命の揺らぎ）

（2026-10-28。利用者の指示：運命のゆらぎが高い時には、関係性のある対象に「らしくない」行動が増えてほしい。見た相手の反応も、動揺・ときめき・惹かれ・蠱惑的に思う・そそられる などが起き、意外な関係に着地するように）

## 1. 仕組み（`js/unlike.js` の `HK.Unlike`、R18 の部分は `js/unlike-r18.js`）

```
運命の揺らぎ chaos ──▶ 区切りの当たり（種と区切りの番号から。本筋の乱数を使わない）
                         │ 当たり
                         ▼
 その区切りに動く人 a と相手 b（同じ場にいる・関係の設定か、惹かれ・好意・緊張が動いている）
                         │ a の気質・態度から「本来はしない」型を選ぶ（12種）
                         ▼
     a の「らしくない」行動 ──▶ b の反応（8種。b の気質・態度・性欲・二人の関係で選ぶ）
                                   │
          ┌────────────────────────┼─────────────────────────┐
          ▼                        ▼                         ▼
  ときめき・惹かれ・蠱惑      そそられる（R18版）        動揺・心配・面白がる・警戒
  （恋愛に進める組だけ）      （体の関係が許される組）     （どの組でも）
          │                        │
          ▼                        ▼
  unl_spark：b から近づく       unl_heat：b から誘う夜
  → 告白・恋人の流れへ          → セフレ・恋人の流れへ
                         ＋ unl_after：a の後日談（恥じる／開き直る／覚えていない）
```

- **回数**：区切りごとの当たりの確率は `U.pStep(x, 区切りの数)`＝見込み `2.4 ×（x ÷ 0.4）²` ÷ 区切りの数（上限 0.9）。揺らぎ 0 では起きない。当たったのに相手と型がそろわなかった区切りは、次の区切りに一度だけ持ち越す。同じ人の同じ型は回の中で一度だけ、一人あたり 2 回（揺らぎ 70 以上は 3 回）まで。
- **相手**：同じ場にいて、関係の設定があるか、惹かれ 12・好意 ±20・緊張 20 を超えて動いている人（揺らぎ 70 以上は同じ場にいるだけでよい）。死んだ人・不在・監禁中（`HK.State.here`）は出ない。`a` が `b` を避けている組（`HK.Avoid.of`）・無関心・恐怖の組では起きない。
- **型（12種。fit が閾値 0.58〈揺らぎ 80 以上は 0.5〉以上のものから、いちばん「らしくない」もの）**：嫉妬しない人の嫉妬／強引な人の照れ／冷静な人の取り乱し／素直でない人の甘え／丁寧な人の毒舌／奔放な人の一途※／臆病な人の大胆※／几帳面な人の物忘れ／無口な人のおしゃべり／面倒見のいい人の突き放し／献身的な人のわがまま／強気な人の弱音（※は恋愛に進める組だけ）。
  文は型ごとの地の文 3 本（相手への一言は 3 本ベース）＋態度9種の「らしさの崩れ」の一文。
- **反応（8種）**：動揺／ときめき／惹かれる／蠱惑的に感じる／心配する／面白がる／警戒する／そそられる（R18版。性欲が強い人、ふつうの人もまれに）。文は反応ごとに 3 本＋見た側の態度9種の一文。
- **値の動き**：ときめき・惹かれ・蠱惑は b→a の惹かれ（+10〜14）、もともと好意が低い組の「惹かれ」は好意も大きく上げる（敵対・不仲からの着地）。警戒は信頼を下げる。気分（emotion.js）も動かす（行動した側は恥じらい、見た側は反応ごと、そそられた側は火照り）。
- **恋愛・体の関係の門**：恋愛（ときめき・惹かれ・蠱惑・近づく）は `HK.canLove` を両方向・恋愛やR18にしない組でない・恋愛：なしの家族でない・`ctx.romanceOk` を両方向（物語型は恋愛の起こりやすさ 0 でない・一途）。体の熱・夜は `HK.State.pairSex`（`HK.Pos.okSex` を含む）・`HK.sexBlocked`・恋愛：なしの家族でない、夜はさらに `HK.TieWarmR18.ok`（描写の設定・恋愛対象・ほかの恋人・クラスメイトを除く）と、受け攻めは `HK.Pos.order`。
  恋愛に進めない組（恋愛：なし の関係・恋愛対象が合わない組など）は、惹かれを上げずに「動揺」（緊張）と、R18版で体の関係が許される組なら「体の熱」に流す。

## 2. 箱庭への取り付け

- **エンジン型**（合コン・出られない部屋・クラスメイト・無人島・ゾンビの街・オメガバース）：共通の出来事 `HK.COMMON` に `unl_flip`・`unl_after`・`unl_spark`（両ビルド）と `unl_heat`（R18版）を足す（`HK.addTo`。族のかたまり pack-rel）。結果に `odd` の印（画面の「らしくない」）。
- **物語型**：入口 `HK.Unlike.story(S, id, live, {n})` が `{a, b, text, why, d}` を返し、呼ぶ側が `HK.Story.sayB` で記録して関係の値（`S.relD`）に `d` を足す。今回は邪神村（2時間ごとの tick）・吹雪の館（夜の場面）・宇宙船（船での暮らし）に 1 か所ずつ差し、3 つの箱庭の設定に「運命の揺らぎ」を足した（エンジン型の全体の設定と同じ id `chaos`）。後日談も同じ入口から出る。物語型では夜（unl_heat）・近づく（unl_spark）はまだない。

| 揺らぎ | 1 回あたりの行動 | 後日談 | 近づく | そそられた夜 | 行動のあった組が結末で恋／夜の線（うち揺らぎ 0 には無かった線） |
|---|---|---|---|---|---|
| 0 | 0 | 0 | 0 | 0 | — |
| 40 | 1.69（箱庭ごと 0.71〜2.58） | 146 | 20 | 2 | 35／22（20／15） |
| 100 | 5.07（同 1.88〜9.54） | 380 | 66 | 2 | 71／48（50／39） |

全年齢モード・全年齢版では「そそられる」「夜」は出ない（揺らぎ 40 で 1.74〜1.78 回）。

## 4. 残した課題

- 物語型の「近づく」「夜」は、各箱庭の恋の流れ（邪神村の「恋人を作る」・館の寄り添う夜・宇宙船の夜）に `S.relD` 経由で間接に効くだけ。直接の続きは今後。
- 「意外な関係」の着地は、揺らぎ 40 で行動のあった組のうち約 1 割が結末の恋・夜の線になる程度。全体の恋・夜の線の数はほぼ変わらず、相手が入れ替わる。もっと着地させるなら unl_spark の値を上げる。
- 物語型の夜（unl_heat 相当）は未実装。ゾンビの街・邪神村は場所が分かれるため、揺らぎ 40 で 1 回を少し下回る。
