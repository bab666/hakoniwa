（2026-10-28。利用者の指示：無関心・恐怖は恋愛ありでも進みづらく。恐怖はより上がりづらい。でかいハプニングが起きないと変化しない。
相手から強引に性的な行為をされた時に無関心でいるのは難しい。恐怖も怯えて応じるだろうけど、より強い恐怖になる。
無関心は劇的なことがあるまで上がりにくく、恐怖はマイナスに変動しやすい。恐怖対象が落ちぶれたら恐怖し続けるのは難しいため、
ゾンビの街や邪神村などの極限系箱庭では、弱みを見たら突き落とす・あえて見捨てて逃げる・「僕は悪くない……」と言いながら売り渡す。
恐怖対象から逃れる行動も性格によっては取る。愛に転じることもゼロではないけど、憎悪や、弱った相手への歪んだ庇護欲に転がることの方が多い。
「あんな巨大に見えていたものがちっぽけだと思った」。これをルールづけて箱庭イベントに適応して）

R18 の「力ずくで迫られる」は `js/cold-fear-r18.js`（R18版だけ）。どれも族のかたまり pack-rel（物語型の pack-story は pack-rel に依存するので、物語型の箱庭でも読まれる）。

## 1. 全体の形

```
           無関心（a→b）                                 恐怖（a が b を恐れる）
 ふだん    恋愛：自動 → 値は凍結（今までどおり）          惹かれ・好意・信頼の上がり ×0.1
           恋愛：あり → 値の動き ×0.25                    好意・信頼の下がり ×1.5、緊張の上がり ×1.3・下がり ×0.5
                                                          脅し・怒鳴り・暴力を向けられる／見る → 恐怖が深まる
 ─────────────────────────────── 引き金（劇的なこと） ───────────────────────────────
 力ずくで迫られる   → 無関心でいられない（憎悪／動揺）     → 怯えて応じ、恐怖が深まる
 （R18版）
 弱ったとき助けられる → 心が動く（無関心が解ける）        → 少し和らぐ（恐怖は消えない）
 ほかの出来事で庇われた・救われた → 同上                  → 同上
 相手が落ちぶれる・弱みを見せる                           → 恐怖は続かない：性格で分岐（下の 4.）
```

- 引き金の出来事は、理由に「無関心の変化：…」「恐怖の変化：…」を書く。変化のときだけ抑えを外して（`ctx._cfRaw`）まとめて動かす。
- 一回の箱庭の組の表は、エンジン型が `ctx._cf`、物語型が `S._cf`（鍵は「抱く側>相手」）。同じ向きに無関心と恐怖の両方があれば恐怖を見る。
- 状態（`p.st`）：無関心は ''（まだ）→ moved（心が動いた）／ahate（憎悪）／shaken（動揺）。恐怖は ''・deep（深まった）・eased（和らいだ）・fled（逃れた）のあいだは恐怖のまま、
  hate（憎悪）・scorn（見下し）・shelter（歪んだ庇護）・love（恋）になったら恐怖は終わる。

## 2. 進みづらさ

- **エンジン型**：`Ctx.prototype.mod` を包み、組ごとに値の動きに倍率を掛ける（`CF.K = { apathy: 0.25, fear: 0.1 }`）。
  - 無関心：「恋愛：自動」は `ties.js` の凍結（freezeInit）のまま。「恋愛：あり」は凍結を外し、すべての値の動きを ×0.25。解けたあとも惹かれの上がりは ×0.5。
  - 恐怖：惹かれの上がり ×0.1。好意・信頼の上がりは、関係の伸びの倍率（恐怖の modsA：好意 0.6・信頼 0.5）と合わせて ×0.1 になるように割る。下がりは ×1.5。緊張は上がり ×1.3・下がり ×0.5。
- **物語型**（関係の値が二人で一つの `S.relD`）：区切りごとに、組の値の上がりを ×0.25（無関心）／×0.1（恐怖）に戻す。
- 無関心・恐怖の「あり」で体の関係だけ止める noSex（`HK.sexBlocked`）・恋愛の門（noLove）は今までどおり。恋に転じるのは 4. の「まれに恋」だけで、そのときも `HK.canLove` を両方向で通す。

## 4. 恐れていた相手が落ちぶれたとき（`CF.choose`）

恐怖は続かない。まず「まれに恋」を見て、そのあと三つの向きを性格で重み付けして一つ選ぶ。

| 向き | 重み（2 乗して比べる） | 行動 |
|---|---|---|
| まれに恋 | 恋愛：あり（`HK.canLove` 両方向・恋愛の欄）で好意 5 超のとき 8% | 恋に転じる（love） |
| 攻撃 | 攻撃性 ×1.2 ＋ CP ×0.7 ＋ 敵視 0.45 ＋ 愛憎 0.45 ＋（高飛車・厳格 0.15） | 極限系の箱庭は下の表、それ以外は見下す（scorn）・言い返す（retort）・縁を切る（cut） |
| 逃れる | AC ×1.1 ＋ 慎重さ ×0.5 ＋（内気・丁寧 0.2） | 相手から逃れる（fled。以後、相手を出来事の相手に選ばない） |
| 歪んだ庇護 | NP ×1.2 ＋（献身・穏やか 0.25） | 「あんな巨大に見えていたものが、今はこんなにもちっぽけだった」――弱った相手を囲う（shelter） |

**極限系の箱庭**（`CF.EXT`：ゾンビの街・無人島・バトルロワイヤル・裁判・邪神村・吹雪の館・人狼・宇宙船）での攻撃の行動：

| 箱庭 | 行動（重み） | 効き目 |
|---|---|---|
| ゾンビの街・バトロワ | 突き落とす（1.1×死ネタの重さ）・見捨てて逃げる（1）・見殺し（噛まれた・毒・けがの相手に 1） | 突き落とすと死ぬ。見捨てる・見殺しは命を落とす見込み（見捨てる 35%・見殺し 55% ×死ネタの重さ×少人数の係数）、生き延びたら恨みが残る |
| 無人島 | 見捨てる（1）・見殺し（1） | 同上 |
| 裁判 | 「私は悪くない……」と売り渡す（1.4） | ほかの人の信頼が下がる・緊張が上がる |
| 邪神村 | 売り渡す（1.2。呪いの痣が出ている相手は除く）・見捨てる（0.8） | 売り渡すと村人に連れ去られる（生贄の候補）。見捨てると 4 割×襲撃の重さで連れ去られる |
| 人狼・吹雪の館 | 売り渡す（1.3）・見捨てる（0.7） | 人狼は疑いが一気に集まる（昼だけ）、館は疑いが強まる・怯えが増す |
| 宇宙船 | 見捨てる（1）・売り渡す（0.8） | 体力が下がる／皆の信頼を失う |

- 殺す行動は、死ネタの重さ（`HK.Dark.f(ctx, 'kill')`）・少人数の係数・「憎悪を持っても殺さない」（`HK.Attr.noKillPair`）・蘇る人（`HK.Special.canRevive`）を通す。殺さない組には突き落とさず（人狼・裁判では売り渡さない）、命は奪わない。
- 死ぬのは `ctx.kill` だけで、出来事の記録を書いたあとに当てる（記録の中で死んだ人が動く文にならないように）。物語型は人を直接殺さず、箱庭の仕組みを使う。
- 「私は悪くない……」は 3 本の台詞（一人称は「私」、口調の辞書で「僕」などに言い換わる）。

## 5. 弱った様子（`CF.weak`）

- エンジン型：ゾンビに噛まれた／毒に倒れた／熱／けが（体力 60 以下・傷）／飢え／爪弾き／いじめの標的／隠していたことを暴かれた／心が折れた／倒れた／酔いつぶれた／追い詰められて取り乱した（ストレス 82 以上）。
- 物語型：邪神村（けが・取り憑かれた・呪いの痣・震え）、人狼（皆から疑われた）、館（犯人と疑われた・怯えきった）、宇宙船（感染症・体を壊した・漂流の恐怖）。
- 恐れる側が、相手を同じ場で見ている（または直前の区切りに同じ出来事に出た）ときだけ。

## 6. 結末

- エンジン型：結末の覚え書きに「恐怖のその後」を足し、関係のまとめ（`HK.TieRel.refine`・`pairText`）を既存の分類（嫌悪・庇護と依存・他人のまま）に寄せる。恋人・殺害・別れの分類は上書きしない。
- 物語型：結末の箇条書き・住人の覚え書き・関係図の★の線（恐怖→憎悪／見下し／歪んだ庇護／逃れた／恋、無関心→心が動いた など）に足す。
