# 夜の能動性の型：騎乗位・受け優位・逆転（2026-10-31・担当E2）

利用者の依頼：「騎乗位、受け優位の展開、あるいは逆転など、夜の性格や能動性に合わせたエッチなイベントが足りない」。
途中の指示：

- 受け優位の展開（誘い受け・襲い受け・受けがペースを握る）と逆転は、**受けの夜の主導が「受けが主導（誘い受け／襲い受け）」のときだけ**。おまかせ・攻めが主導の人では起こさない（性欲・夜の性格・疲れ・媚薬だけを理由に起こさない）。
- 騎乗位などの体位は、攻めが主導したまま「攻めが受けを上に乗せる」形ならおまかせでも出てよい（体位の変化）。受けが自分の意思で跨るのは、受けが主導の設定のときだけ。
- すでにある夜の性格を展開に反映する（攻めの性格で展開を、受けの性格で反応を分ける）。夜の性格の種類が無い人は、態度 9 種（E4 の `HK.Attr.nightAtt`）で書き分ける。
- 「相手に合わせる」＝乗り気でなくても相手の嗜好に付き合う（E4 の `HK.Attr.nightAccom`）。
- 住人の設定「夜の好み」は足さない（今ある設定だけで決める）。

## 2. 判定の表（設定 → 主導・体位・逆転）

`HK.Initiative.plan(ctx, T, U, o)`：T＝攻め（挿れる側）、U＝受け。向きは `HK.Pos.order` で決めたもの（呼ぶ側が並べる）。

### 2-1. 差さない組
- 全年齢・受けが攻め指定の組（`HK.Pos.hardTop(U, T)`）・性器なしの人がいる組（`HK.NoGen.on`）。

### 2-2. 受けの夜の主導が「受けが主導」（U の `lead` が sasoi／osoi）のとき

| 段 | 確率 | 中身 |
|---|---|---|
| 誘い方・襲い方（lead） | 85% | 受けの夜の性格の種類（maso＝強くされにいく、sweet＝甘く誘う、mean＝挑発して誘う、shy＝言えずに体で誘う、sadist＝攻めを支配しにいく）。種類が無ければ態度 9 種（強気＝押し切る、厳格＝淡々と、意地っ張り＝言い訳しながら、穏やか＝やさしく、健気＝尽くす、冷静＝見抜く、奔放＝遊ぶように、恥じらい＝体で、丁寧＝申し出る）。受けが「相手に合わせる」で攻めがマゾなら「付き合って襲う」一文を頭に |
| 攻めの手を縛る（合意） | 襲い受けで、攻めが自分で攻めを選んでいない・受けが sadist／mean か態度が強気・奔放・冷静のとき 30%（本文にすでに縛る・拘束の文があれば使わない） | ネクタイ・リボンで緩く結ぶ。いやなら言ってと確かめる |
| 攻めの応じ方（tresp） | 80% | 攻めの夜の性格の種類（sadist＝取り返そうとする、sweet＝応える、shy＝戸惑う、mean＝悪態）。種類が無い・maso なら態度 9 種 |
| 型の変化（change。1 回の場面で 1 回まで） | 襲い受け 55%・誘い受け 40%、受けの性欲が強い ＋10%、媚薬・酔い・発情 ＋8%、同じ二人の二度目以降 ＋5% | 役割の入れ替えが成り立つ組なら 4 割が swap。残りは誘い受けで 65%・襲い受けで 50% が ride_b、ほかは shift |
| 理由の一文（why） | 型が変わるとき必ず | 発情（オメガバース）＞媚薬（ロッカー）＞酔い（合コン）＞攻めの疲れ（同じ二人の二度目以降の 6 割）＞受けの性欲（強いときの 7 割）＞攻めに煽られた（攻めが sadist・mean の 6 割）＞主導の設定 |

- ride_b（受けが自分の意思で跨る）：男×女・男どうし＝受けが攻めの腰に跨り、自分の速さで動く。女×女＝攻めの太腿・顔の上に跨り、攻めの指・舌に自分で押しつける。女攻め×男＝受けの男性が上で動くが、深さと速さは下の女性が言葉で決める（受けに男性器が無ければ shift に替える）。最後に「上で崩れる／攻めが先に音を上げる／攻めが下から突き上げる」の一文。
- shift（主導だけが移る。受け攻めは指定どおり）：受けが攻めを座らせて速さを決める・耳元で指図する・指を自分の好きな場所へ導く・下から攻めの腰を掴んで揺れを止める など。
- swap（役割の入れ替え）：**二人とも攻めを選んでおらず（`HK.Pos.hardTop` でない）、二通りの向きが成り立ち（`HK.Pos.dirOk` を両方向）、相手ごとの指定・攻め度で向きが決まらない（`HK.Pos.prefer` が null）組だけ**。体の組が合うこと（男×女で受けに男性器がある・女攻め×男で受けに男性器と攻めに女性器がある・女×女）。果てたあとの二度目として、今度は受けだった人が挿れる側（女×女は指・舌）に回る。
- 押し倒す・仰向けに寝かせる・縛る文は、攻めが自分で攻めを選んでいるときは使わない（表の H 印の文だけを使う）。

### 2-3. 攻めの展開（主導は攻めのまま。夜の主導の設定に関係なく）

| 攻めの夜の性格 | 確率（受けが主導の場面では 0.35 倍の起点） | 展開と体位 |

| shy | 同上 | ぎこちなく主導し、受けに促されて動く・顔を見られないよう横から |

| どちらも出さないとき | 12%（性欲が強い ＋6%） | 攻めが受けを上に乗せる・向かい合う・横から（攻めが主導したままの体位の変化） |

喘ぎは `HK.Moan.say`（受けの態度・口調・濁点・♡・小説調は ♡ なし）。型の段の喘ぎは短い声（言葉の部分が 9 字以下）に寄せ、場面の部品と共有する「使った喘ぎの覚え」にすでにある声は使わない（無ければ声を足さない）。言葉のある長い声は E1 のプレイの段などと同じ声になりやすく、同じ文が三つの記録に並ぶため（点検 state の S10）。

### 2-5. 同じ二人の連続
同じ二人で、前の場面と同じ型（攻めの展開・型の変化・誘い方の有無）になったら、型の変化を外すか、攻めの展開を体位の変化に替える（出来事が型を指定したときは替えない）。

## 5. API（E3 が一人用・物語型に取り付けるとき）

```js
var I = HK.Initiative;
/* T＝攻め・U＝受け（HK.Pos.order で並べる）。o：
   mode 'mf'|'ff'|'fm'（省けば体から）、ero（男性向け）、heat／drug／drunk（その場の状態）、nth（同じ二人の回数）、
   memo（同じ二人の連続を避ける置き場。回ごとのオブジェクト）、ini（型の指定：{ lead: true|false, dev: true|false, react: true|false, change: 'ride_b'|'shift'|'swap'|'' }）、
   r（乱数。省けば名前から。本筋を変えたくなければ I.rngFor(T, U, 本文) を渡す） */
var pl = I.plan(ctx, T, U, { ero: ero, memo: S._iniMemo || (S._iniMemo = {}), r: I.rngFor(T, U, text) });
if (pl) text = I.apply(text, pl, { after: 事後の文, anchor: 感じていく段の文（あれば） });   /* text は {a}{b} のまま・段落は改行区切り */
/* 段だけ欲しいとき：var p = I.parts(pl) → { lead, mid, end }（{a}{b} のまま）。lead＝始まりの段の後ろ、mid＝果てる段の前、end＝果てたあと（入れ替え） */
```

- 判定の窓口：`I.kindOf(a, b)`（夜の性格の種類）・`I.attOf(a, b)`（態度）・`I.accomOf(a, b)`（相手に合わせる）・`I.leadOf(T, U)`（受けの夜の主導）・`I.canSwap(T, U, mode)`。
- 点検用：`HK.Initiative.log = []` で、差した型を `{ a, b, mode, kind, kindU, att, attU, accT, accU, lead, lsty, bind, tresp, dev, pose, react, change, why, ero, H, place, src }` で記録する。
- `opt.noIni`（ThickSex／ThickEro の opt、TKC の o）で型を差さない。
