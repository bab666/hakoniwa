# 催眠：「暗示の方向＝エッチなものだけ」でエッチにならない不具合（2026-10-31 担当SA）

利用者の報告：「催眠の箱庭で催眠の内容をエッチのみにしていても、エッチな内容にならなくなった」。

## 1. 原因

今日の変更による退行ではなく（今日より前の版 0ee7840 でも同じ数字）、前からある判定が「エッチなものだけ」を選んだときにも黙って平和な暗示へ落としていた。計測（下の表・`/tmp/hk-scratch/SA/measure.js`、各マス 24 回）で、性的な暗示が一つも出ない回の原因は次の 4 つに分かれた。

| 原因 | 当たる設定 | 前の振る舞い |
|---|---|---|
| (1) 描写の濃さ「ぼかす」 | `okSug` の `if (env.lewd === 'low') return !g.lewd;` | 「エッチなものだけ」でも性的な暗示が 0。ぼかした文 `SM.SUG_LOW` は使われていなかった（届かない文） |
| (2) 住人のかけ手と関係のない二人・合意のない展開 切 | 関係がないとき、かける側の種類を 5 種から乱数で選ぶ。恨み・ストーカー（2/5）を引くと `p.noForce`（いたずらだけ） | ほどほど／濃いめ・2人・切で、エッチが出た回は 38%（モブのかけ手は恨み・ストーカーを同僚・友人・恋人に替えていたが、住人のかけ手は替えていなかった） |
| (3) 関係「敵対」「ライバル」・合意のない展開 切 | 催眠プレイにする見込みが `HK.sexTieK`（敵対 0.6） | 4 割の回は恨みのまま、性的な暗示が 0 |
| (4) 体の関係にならない組（`p.noSex`） | 恋愛対象・受け攻め・R18に参加しない・性行為の相手の固定・恋愛やR18にしない相手・「恋愛：なし」の家族・性欲「なし」（切のとき）・夜の起こりやすさ 0（切のとき）・かける相手「恨み」「ストーカー」（切のとき） | 理由を出さずに平和な暗示へ切り替え（`if (env.mode === 'lewd' && !g.lewd && !p.noSex) return false;`） |

- 1人（モブがかける）で性的な暗示が 0 の回（各マス 1〜2 回）は、催眠に「かからない」（誘導で三回とも失敗）か、最初の暗示の前に目を覚ました回で、設定の不具合ではない（今回も変えていない）。男女の組み合わせで数字は変わらない（恋愛対象・受け攻めを決めていない住人では、どの組でも okSex が通る）。
- 下調べで「fm・ff・mm の組で 24 回中 14 回」とあったのは (2) によるもの（組の違いではなく、種と乱数の巡り合わせ）。
