# 関係「双子」の追加（2026-10-31 担当TW）

利用者の指示：「兄弟をベースに、関係性に双子を追加してほしい。各種イベントも調整」。
CLAUDE.md の「関係性は増やさない」は、この指示のための例外。

## 1. 定義（`js/ties.js` の `T.twin`。両ビルド同じ）

| 項目 | 双子 twin | 兄弟姉妹 sibling | 兄弟（親友のよう）sibclose |
|---|---|---|---|
| 表示名 | 双子 | 兄弟姉妹 | 兄弟（親友のよう） |
| 系統 | `like: 'sibling'`・`family: true` | 家族 | `like: 'sibling'`・家族 |
| 初期値（好意・信頼・緊張） | 42・52・5 | 30・40・8 | 45・50・3 |
| 伸びの倍率（mods） | 惹かれ 0.08・信頼 1.25・緊張 0.85 | 惹かれ 0.08・緊張 1.1 | 惹かれ 0.08・信頼 1.3・緊張 0.75 |
| 明るさ pol・引き pull | 2・2.0 | 1・1.6 | 2・1.9 |
| 行動の倍率 bias | 助け 1.8・絆 1.7・衝突 1.1・恋愛 0.1・戦い 0.25・裏切り 0.25 | 助け 1.6・衝突 1.3・恋愛 0.1… | 助け 1.7・絆 1.6・衝突 1.0… |
| 恋愛 | なし（自動）。**「恋愛：あり」は選べない**（`loveLock`） | なし（「あり」も選べる） | なし（「あり」も選べる） |
| 信頼の下限 | 30（家族） | 30 | 30 |

- 恋愛：既定は「なし」（`loveDef: 'no'`）。`loveLock` で、`HK.tieLoveOK`・`loveOn`（`HK.tiesLove`・`HK.tieLoveNorm`）は「あり」を無視し、`HK.Ties.expand` が `love: 'ok'` を外す。設定画面の「恋愛」の欄にも「あり」を出さない（`ui-ties.js`）。家族の「恋愛：あり」の経路（`HK.tieFamLove`）は双子では通らない。
- `HK.canLove` は双子の組で偽（`HK.Ties.after` の `loveOff`、`p.kin`・`noLove`）。体の関係も `HK.Pos.okSex`・`HK.sexBlocked` の側で止まる（兄弟と同じ）。
- 選択肢：家族・血縁のまとまりの「兄弟（不仲）」の次。追加の欄は「上下」（`HK.SIB_ELDER`。既定は上下なし＝双子どうし、一人目・二人目を選べば「双子の姉」「双子の弟」）・「二人の仲」（家族の仲 kg：良好・不仲）・過去・出来事のオン／オフ。
- 文字からの読み取り（まとめて読み込む）：「双子」「ふたご」「双生児」「双子の兄弟／姉妹／兄妹／姉弟／きょうだい」「双子の兄／姉／弟／妹」。「双子で不仲」は家族の仲：不仲。
- 同じ二人に兄弟（兄弟姉妹・庇護・親友のよう・不仲・義理）と双子の両方は持てない：`HK.Ties.expand` で後から付けたほうを残す（`pining-core.js` が双子のある回で expand を通す）。
- 代表の関係の順（PRIO）は庇護の次、兄弟姉妹の前。「守りたい相手」（focusFor）の重み 4（兄弟は 3）。
- 続柄（`sib-word.js`）：双子の関係は年齢によらず双子。同性は互いに「双子」（まとめは「双子の姉妹」「双子の兄弟」）、異性は「双子の兄」「双子の妹」（まとめは「双子の兄妹」）。上下の欄で選べば「双子の姉」など。呼びかけ（{sibcall}）・弟妹から上への自動の呼び方は、双子では付けない（名前で呼ぶ＝上下を薄く扱う）。設定欄の注意：年齢が違っても双子として扱う旨。

## 2. 既存の兄弟の出来事との対応

`like: 'sibling'` なので、`HK.Ties.has(ctx, a, b, 'sibling')`・`HK.tieHas`・`Ties.find` で兄弟を見ている出来事（tie-rel.js・persona の家族の場面・zombie の tieT など）は、そのまま双子にも出る。種類を表で直接見ているところは、双子を足した（表の値は親友のようなきょうだいと同じ。兄弟（不仲）・庇護の専用の出来事は双子には出さない）。

## 4. 文の例

- 以心伝心：「誰かの冗談に、アキラとミナトは同じ間で吹き出した。笑い方の癖まで、鏡に映したようにそっくりだった。アキラは笑いをこらえながら言った。アキラ「あなたの考えていること、全部分かる気がします」」
- 出られない部屋：「扉の紙のお題を読んだミナトとアキラは、顔を見合わせた。二人の答えは、言葉にしなくても同じだった。ミナトはアキラの手を取って言った。ミナト「大丈夫。二人なら、何とかなる。いつもそうだった」」
- 比べられる（無人島）：「ユキノが、悪気なく言った。ユキノ「顔はそっくりなのに、性格は全然違うね」ミナトは、子どもの頃から何百回も聞いてきた言葉だと思った。アキラが気づかわしげにミナトを見た。ミナト「あの……僕たち、そんなに、違うかな……」」
- モブを騙す（ゾンビの街）：「ミナトとアキラは、通りすがりの生存者の前で入れ替わってみることにした。ミナトはアキラの名前を名乗り、アキラはミナトの癖をまねて隣に立った。通りすがりの生存者は二人の顔を何度も見比べたが、とうとう最後まで気づかなかった。ミナト「やった、まだまだ現役！　次は誰を騙す？」」
- 人狼（陣営が違う）：「アキラは、ミナトと同じ陣営だと言わんばかりに、片割れの肩に手を置いた。本当の陣営を知っているのは、自分だけだった。アキラは笑顔のまま言った。アキラ「ちょっとだけ聞いてください！　生まれたときから見てきた人のことは、分かりますから！」」
