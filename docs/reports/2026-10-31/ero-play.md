# プレイ幅の増強：前立腺・結腸・乳首・喉奥（担当E1・2026-10-31）

R18版だけのファイル `hakoniwa-full/js/ero-play-r18.js`（`HK.EroPlay`。`_order.txt` の late、`attr-race-r18.js` の後ろ）。
既にある共通の山場に「前立腺いじり・結腸責め（奥）・乳首責め・イラマチオ（喉奥）」の段を差し込む。既存の文は消さない。
**住人の設定は足していない**（利用者の指示で「夜の好み」の欄は取りやめ）。どのプレイが出るか・どう進むか・受けがどう反応するかは、今ある設定だけで決める。

## 1. どこに差すか（入口）

| 箱庭 | 差し込む口（`HK.wrap`） | 差す位置 |
|---|---|---|
| 出られない部屋（二人）・合コン／無人島／ゾンビの共通の夜（`tie-warm-r18.js` など）・オメガバースの男性向けの山場 | `HK.Attr.raceWeave`（`thick-sex.js` の `HK.ThickSex.scene`・`thick-sex-ero.js` の `HK.ThickEro.scene` が最後に呼ぶ、種族のプレイの差し込み口） | 前戯の段のあと（喉奥・乳首・前立腺の指）／繋がる段のあと（前立腺の角度・結腸・受けが自分で胸を触る）／果てる段の頭（前立腺で果てる・奥だけで果てる・胸だけで先に果てる） |
| オメガバース・無人島・ゾンビの小説調の山場（`omega-thick-kit.js` の `HK.TKC.body`） | 同じ `raceWeave`（`{T}{U}` の段落） | 同上 |
| 出られない部屋の三人・ロッカーの大人数（`trio-talk-r18.js` の `HK.Trio3.begin`） | 組み立ての `text()` の前 | いちばん初めの組（攻め→受け）の前戯の段・最中の段 |
| 媚薬ロッカー（二人）のロッカーの中で繋がったとき | `HK.LOCKER.nightLine`（deep。一組に一回） | その段の後ろ。狭いので喉奥と、寝台・シーツの文は使わない |
| 媚薬ロッカーのベッド（`solo-locker-bed.js`） | `HK.Attr.racePlay`（fore／mid） | 前戯のあと／繋がる段の終わり（山場の頭の一文もここ） |

- 物語型（`r18-thick.js` の名前を埋めた段落）・一人用は差さない（担当E3 が `HK.EroPlay.SCEN` に箱庭を足し、下の入口を呼ぶ）。
- `HK.Load.onChunk` で、後から届いたかたまり（ロッカー・三人の組み立て）にも取り付ける。
- 本筋の乱数（`ctx.rng`）は使わない。入力の seed・二人の名前・場面の番号から別の乱数を作る。**差し込まない回の結果はこれまでとまったく同じ**。

## 2. 入口（E3 が使う API）

```js
var EP = HK.EroPlay;
EP.SCEN.dungeon = 1;                       // 段を差す箱庭を足す（raceWeave・Trio3 の口はこれで効く）
var o = { mode: 'mf', ero: true, place: '', R: EP.rngFor(T, U) };   // mode: mf／fm／ff（場面の体の組）
var plan = EP.plan(T, U, o);               // { keys:['nip','pros'], init:'a'|'b', why:[…], kT, kU, aT, aU, accT, accU } か null
var b = EP.build(T, U, plan, o);           // { fore:[段落], mid:[段落], peak:'' }（{a}＝攻め・{b}＝受け。喘ぎ・擬音は埋めてある）
var t = EP.paint(b.fore.join('\n\n'), T, U, 'name');   // 'ab'（{a}{b} のまま）／'TU'（{T}{U}）／'name'（名前）
EP.weave(arr, T, U, { fore: 1, mid: 2, climax: 5 }, { mode: 'mf', ero: false, ph: 'ab' });  // 段落の配列に差す（plan と build を中で呼ぶ）
EP.log = [];                                // 計測・点検用（場面ごとに { keys, kT, kU, aT, aU, combo, anat, hardTopU, text … }）
```

- `o.force`：合意のない場面（`HK.Pos.forcing()` の中は自動で真）。`o.place: 'locker'`：喉奥を出さず、寝台・シーツの文を外す。
- `o.rel`（'lover'／'casual'）・`o.heat`（'drug'／'omega'）・`o.nth`（同じ夜の何回目か）・`o.lewd`（'high' で起こりやすい）。取り付けの口では自動で入る。
- `EP.kindOf(a,b)`・`EP.attOf(a,b)`・`EP.accomOf(a,b)`：夜の性格の二軸と「相手に付き合っている」の判定（attr.js の窓口 `HK.Attr.nightKind／nightAtt／nightAccom` をそのまま呼ぶ。仕様は `night-attitude.md`）。
- `HK.Moan.muffle(喘ぎ, R)`：喉を塞がれた声（仮名を「ん・ぐ・ぅ・ぶ」に崩す）。

## 3. プレイごとの条件（解剖・合意）

| プレイ | 成り立つ組 | 出ない組 | 段 |
|---|---|---|---|
| 前立腺 | 男×男（攻めが男性器）・ふたなり×男・女攻め×男（指で、跨りながら） | 受けに女性器がある組（男×女・女×女・ふたなりの受け） | 前戯（指で探る・見つける・反応が変わる・指を抜く）→ 繋がる段（角度・擦る・声の変化。女攻めは跨ったまま指で）→ 果てる段の頭（触れずに後ろだけで／前と同時に） |
| 結腸 | 攻めに男性器・受けが男性器だけ（後ろで繋がる） | 女性器の受け（{ナカ} の奥の表現のまま）・女攻め×男・女×女 | 繋がる段のあと（行き止まりの先へ）→ 果てる段の頭（奥だけで） |
| 乳首 | 全部（男×女・女×女・女攻め×男・男×男） | — | 前戯（攻めが責める）→ 繋がる段のあと（受けが自分で触る。5 割）→ 果てる段の頭（胸だけで先に果てる。4 割） |
| 喉奥 | 攻めに男性器（男×女・男×男・ふたなり×女／男） | 女×女・女攻め×男・ロッカーの中 | 前戯のあと（合意の台詞 → 喉の反応・涙・息・崩れた声 → 引き抜いて咳き込む） |

- 合意：喉奥と結腸は、受けの夜の性格が mean（強がり）のとき合意の場面では起こさない（喉奥は重み 0）。shy の受けは「怖がりながら頷く」台詞。
- **合意のない形**は、`HK.Pos.forcing()` の中（既存の敵対・恐怖の強引な経路）で、内容のスイッチ「合意のない展開」が入・攻めの夜の性格が sadist・攻めに男性器、のときだけ「強いられる喉奥」（45%）。ほかのプレイは出さない。
- 「暴力をともなう性描写」が入で攻めが sadist のときだけ、押さえつける・髪を掴む一文を足す。切なら足さない（痛めつける語は書かない）。
- 一回の場面に 1〜2 種（2 種は 2 割強。sadist の攻め・maso の受けは 4 割）。同じ二人の前の場面で出たプレイは候補から外す（連続しない）。
- どの段も、最初の段の頭に「きっかけ」（理由の一文＋誰が何を求めたか）を入れる。2 種目は「それだけでは終わらなかった。」でつなぐ。
- 攻め・受けの向きは変えない（受けは山場の受けのまま）。体の関係の可否は既存の `HK.Pos.okSex`／`HK.State.pairSex` を通った場面だけに差すので越えない。

### 4-3. 「相手に合わせる」（相手の嗜好に付き合う）

- `HK.Attr.nightAccom(a,b)`（無いときは生の値が match で種類が決まる人）。
- 攻めが付き合う（受けが maso で攻めが sadist に寄る）：きっかけは「{b}が望んでいるのを知っていたから、あえて強く責める」。最中に「責める手つきとは裏腹に、目はいつもの{a}のまま」。終わりに攻めの一言「……これで満足？　あなたが望んだんだからね」など（3 本）。暴力の一文は足さない。
- 受けが付き合う（攻めが sadist で受けが maso に寄る）：言い出すのは攻め。きっかけに「自分から望んだわけではなかったが、{a}が欲しているならと頷いた」（合意はある）。反応は本人の態度の列＋「乗り気ではなかったが、拒まずに受け入れ続けた」。終わりに受けの一言「……これで、満足？」など（3 本）。
