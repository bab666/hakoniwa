# 性的な語の印（第1段）

R18の文に出る性器などの語を、ソースでは `{男性器}` のような**印**で書き、結果を仕上げるときに、作風・濃さ・話し手の態度・住人の設定で語を選んで置き換える仕組み。第1段では、仕組みを作り、はっきりした語（段1）だけを機械で印に置き換えた。

## 2. 列の選び方

- **地の文**：描写の作風（`env.style`：novel＝小説調／ero＝男性向け）× 描写の有無（`env.lewd`：low＝ぼかす／mid＝やわらか／high＝直接）。読み方は `HK.Lewd.ero`・`HK.Lewd.lv`（lewd-unify.js）。
- **台詞**：話し手の態度（`HK.personaOf` の9種）。shy・tsun＝ぼかす、devoted・gentle・polite＝やわらか、proud・free＝直接、cool・stern＝小説調では医学的・男性向けでは直接。作風が男性向けなら男性向けの列。
  - 話し手は「名前「…」」の形で取る（part-words.js の `speaker()` と同じ）。取り方は `lewd-words.js` の `speakerOf()` 一か所にまとめてあり、`HK.LewdWords.speakerHook` で差し替えられる（あとで `e.seg` の話し手に切り替えるときはここだけ直す）。
  - 話し手の分からない台詞（司会・客・モブなど）は地の文と同じ列。
- **住人の設定「性器の呼び方」**（part-words.js の `partWords`・`partM`・`partF`）があれば優先する。台詞は話し手の、地の文はその体の持ち主（印の直前の「名前の」）の設定。soft＝ぼかす、direct＝直接、medical＝医学的。自由記入は `{男性器}`（partM）・`{女性器}`（partF）に使う。
- **（2026-10-27 追記）「名前の」のない印の持ち主**：地の文で印の直前に「名前の」がないときは、文と場から持ち主を推し量る（`lewd-words.js` の `guessOwner`）。文に名前の出る住人（いなければ出来事の場の住人）のうち、その体を持つ人（{男性器}・{亀頭}＝男性器のある人、{女性器}・{陰核}＝女性器のある人）がただ一人ならその人。胸・ナカなど誰にでもある体は、候補の全員の設定が同じときだけ。「自分の」は文の主語、「〇〇の」（住人でない人・相手・彼 など）は持ち主なし。住人でない人の語（客・店長・スタッフ・相手…）がある文、場の住人が一人で本文に住人でない人の語がある出来事には当てない（箱庭が記録に `e.npcG`＝相手のモブの体 'm'／'f'／'mf'／'' を付ければ、モブにその体がないときだけ当てる）。
- 台詞の話し手は「名前「」の形のほか、台詞の区分（voice.js が記録に隠して持たせる `e._sq`）からも取る（`「＠名前＠…」` の台詞にも話し手の設定が効く）。**自由記入（partM・partF）は台詞でも地の文でも、その人の体の語にだけ使う**（台詞の中の持ち主は `quoteOwner`：「名前の」→その人、「私の…」→話し手、「あなたの…」→話し手でないただ一人、それ以外はその体を持つただ一人）。作風の列（ぼかす・直接・医学的）は、台詞では話し手の設定。
- **同じ文の同じ印は同じ語**。候補が二つ以上あるときは、文から決まる番号（hash）から始めて、その回でまだ使っていない語を選ぶ（emotion.js の `X.word` と同じ考え方。乱数は使わないので、同じ入力なら同じ結果）。
- 差し込み場所：`HK.Voice.processResult` のあと（書き下ろし・口調の言い換えのあと）。読み込み順は part-words.js の直前なので、part-words.js の言い換えはこのあとに働く。

## 3. 書き方の決まり（新しく R18 の文を書くとき）

- 性器・胸・尻・精液・愛液などは、語を直接書かずに印で書く：`{a}は{b}の{男性器}を根元まで呑み込んだ。`／`{a}「{b}の{ナカ}、あったかい……」`
- 印は名詞として使う。後ろは助詞・句読点・「」にする（`{男性器}汁` のような複合語は作らない。複合語にしたいときは語をそのまま書く）。
- 両ビルド共通のファイルでは、印を使う文も `/* r18:begin */`〜`/* r18:end */` の中に書く（全年齢版のビルドは、印が bundle の文字列に残るとエラーで止まる）。
- 医学的な語（陰茎・ペニス・膣・陰部）を診察・研究の場面でわざと使うときは、語をそのまま書いてよい（置き換えない）。
- 企画名・題名・言葉遊び（しりとり・伝言）のように、語そのものが大事な所は語をそのまま書く。
- 生成の途中で本文の語を見る判定（`HK.Pos.MALE_RE`・pos-nogen.js・safe.js の HARD など）は、印も見るように直してある。新しく判定を書くときは、印も当たるようにする（`HK.LewdWords.direct(text)` で印を決まった直接の語に戻してから見るのが簡単）。

## 4. 点検の切り替え・新しい点検

- `HK.LewdWords.MODE = 'direct'` で、いつも「直接」の列で置き換える（ぼかした語だと pos-audit が性器の取り違えを見逃すため）。`hakoniwa-tools/tone-check/lib.js` の `openBuild(dir, hash, { lewdMode: 'direct' })`、または環境変数 `HK_LEWD_MODE=direct`。pos-audit・state-audit・orient-audit はこの切り替えを入れて開く。
- **V10**（pos-audit）：`{男性器}`・`{亀頭}` の印なのに、その場の住人（出来事の登場人物と本文に名前が出る住人）の誰にも男性器がない／`{女性器}`・`{陰核}` なのに誰にも女性器がない。印を語にするときに `HK.LewdWords.V10` にためる。住人でない相手（客・獲物・魔物など）が出る文は数えない。
- **T10**（text-audit）：結果（記録・結末の行）に印が残った。
- 全年齢版のビルドの検査（build.js の EXPLICIT）に印の形を足した。
- 実行時の保険：両ビルド共通の `js/lewd-mark.js`（性的な語は書いていない）。結果に印が残っていたら、R18版で全年齢モードでなければ地の文の列で、そうでなければ無難な語（胸→胸、尻→腰、後ろ→後ろ、ナカ→奥、ほかは「そこ」）に替える。

## 5. 第1段で置き換えたもの・置き換えなかったもの

- 置き換えたのは、R18専用ファイルと、共通ファイルの r18 印の中の文字列リテラルにある、はっきりした語だけ（635 件・32 ファイル）。置き換えの道具は `scratchpad/words/replace.js`（作業の記録）。
- 置き換えなかったもの：
  - 書き下ろし（tone-fix*.js・voice-override*.js など）の鍵に一致する台詞（7 件）。鍵と台詞を同時に置き換える必要があるが、tone-*.js は別の作業と重なるため今回は触っていない。`replace.js --keys` で鍵ごと置き換えられる。
  - 喘ぎ（moan-*.js）の `{p}`、判定の表（part-words.js・pos-fm.js・pos-nogen.js）。
  - バラエティ番組の企画の表（solo-variety-data/more/extra/plus.js）：企画名（【乳首当てクイズ】など）と台詞の語がそろっている必要がある。
  - 医学的な語（陰茎・ペニス・膣・陰部）、最奥・子宮口・子宮・裏筋・睾丸・玉袋・花弁（印がない語、または花の意味）。
  - 複合語（ちんぽ汁・アナルビーズ・人工精液）、言いよどみ（「お、おちんちん」）、語だけを括った言葉遊び（「ちんちん」と言ってしまい）、題名らしい短い文字列。

## 6. 第2段の方針（やっていないこと）

- 段2（胸・尻・先端・竿・精・穴・中・奥・蜜・花芯・下腹 など、性的でない意味と混ざる語）は、人が文脈を見て決める。「中」「奥」は文の骨組み（「奥まで」など）なので印にしない。
- 書き下ろしの鍵の置き換え（`replace.js --keys`）は、tone-fix の作業が落ち着いてからまとめて行う。前後で `dict-regress.js` の成績と、collect で書き下ろしが当たった数が減らないことを確かめる。
- 喘ぎの `{p}` のつなぎ替え案：moan-engine.js の `fillPart` で、`ctx.p` が無く相手に男性器があるとき、`PART_DEF` の語の代わりに `{男性器}` を入れる。喘ぎは「名前「…」」の形で本文に入るので、lewd-words.js が喘ぐ人の態度で語を選ぶ（今の PART_DEF の「proud・tsun・free・cool はちんぽ、ほかはおちんちん」は、表の列に寄せる）。
- 台詞の話し手を `e.seg`（台詞・地の文の区分）から取るようにすると、「名前「」」の形でない台詞にも態度の語選びが効く。
