# 台詞・地の文・引用の区分（seg）の設計

2026-10-26。事前調査（提案2・案α）を受けて入れた仕組みの説明。ソースの書き方（`名前「台詞」` を文字列に直接書く）は変えない。

## 1. 何ができるか

結果の記録（`res.log`）の各項目 `e` に、文を区分ごとに分けた `e.seg` が付く。`e.text` はこれまでどおり残る。

```
e.seg = [
  { t: 'n', s: '店の外の自販機の前で、カオルはミナトに向き直った。' },
  { t: 'l', who: 3, s: '「酔った勢いだと思われても、構いません。」', h: 1 },
  { t: 'n', s: 'ミナトは困ったように笑った。' },
  { t: 'l', who: 1, s: 'ミナト「今日会ったばかりですし……」', nm: 3, h: 2 }
]
```

- `s` を順につなぐと `e.text` と同じ文になる（seg-audit の join で確かめる）。
- `t`（区分）
  - `n` 地の文
  - `l` 台詞行：文の頭の台詞か、`名前「` の直後の台詞（話し手あり）
  - `q` 地の文に埋まった発話：`アキラは「……」と言った` の「……」（話し手あり）
  - `c` 名詞の引用：「〜」という話・札の文字・題名・目標（話し手がいても口調を変えない）
  - `m` 喘ぎ・モブ：「 の頭に `⁠` の印があるもの、住人以外の人物の台詞（`名前「` の形なら `who` にその人）
  - `u` 話し手が決まらない発話
- `who`：話し手の住人の番号（`input.chars`・`res.chars`・`res.heroes` の番号）。
- `nm`：`s` の頭にある名前の長さ（`名前「台詞」` の形のとき。名前は台詞の側に入る）。
- `h`：長い文の改行（`HK.fmtLong`）で一つの台詞の塊になるもの。同じ番号が一つの塊。

`e.seg` は数え上げない属性（`Object.defineProperty` の enumerable:false）なので、セーブ・履歴・共有の JSON にも、結果の指紋（regress.js）にも入らない。
保存から開いた記録は `HK.Seg.of(e, res)` が文から作り直す（voice.js の話し手の判定をできあがった文にかけ直す。試した 630 件の「」で、作り直した区分と話し手は元とすべて一致）。

## 2. 仕組み

1. **区分を決める**（js/voice.js の `V.processText`）：台詞を整えるとき、いちばん外側の「」ごとに区分と話し手を決める。
   `V.processResult` が記録ごとに `V._segBuf` に配列を渡し、processText がそこに `{k, w}` を積む（k は `s` 話し手のある発話／`c`／`m`／`u`、w は住人の番号）。
   区分は文の中に印として残さず、記録に隠しの属性 `_sq`（数え上げない）として持たせる（`HK.Seg.keep`）。
   文の中に印を残すと、あとの仕上げ（part-words.js の名前「 の判定、safe.js の喘ぎの台詞の長さ、全年齢の言い換え）の結果が変わってしまうので、横に持たせる形にした。
2. **seg にまとめる**（js/voice-seg.js。`_order.txt` の `reset.js` のすぐ後。HK.simulate を包むほかのどの処理よりも外側）：
   ほかの仕上げ（全年齢の言い換え・語の差し替え・モブの呼び名など）がすべて済んだ文に合わせて、`_sq` を「」に当てはめて `e.seg` を作り、`_sq` を消す。
   台詞の中身が同じものを先に当て（全年齢の言い換えで消えた台詞は飛ばす）、数が同じなら順番で当てる。どちらでも合わないときは文から決め直す（`V.quoteKind`）。
   全箱庭 10 回ずつで、中身で合った 10,627 件・順番で合った 3 件・決め直し 0 件（R18 版）。
3. **文の形での分け直し**（voice-seg.js の `refine`。言い換えには使わない）：話し手の決まらない「」（u）を、題名の枠（「目標は」「型は」「：」「→」）・
   台詞らしくない言い方（「〜」で・「〜」だ・する、並んだ短い「」）なら `c`、同じ文に住人以外の主語・呼び名があれば `m` に分け直す。

## 3. ソースで話し手をはっきりさせる目印

推定が誤る文だけに使う。画面には残らない（processText が外す）。

| 書き方 | 意味 |
|---|---|
| `「＠{a}＠台詞」` | 話し手を {a}（住人の名前）に固定し、その人の口調で言い換える。3本の台詞でも頭に `＠{a}＠` を付ければよい（`「＠{a}＠くだけ｜硬い｜敬語」`） |
| `「＠{m}＠台詞」` | ＠と＠の間が住人でない名前なら、話し手なし（モブ。口調を変えない） |
| `「＠＠題名」` | 名詞の引用（区分 c。話し手なし、口調を変えない） |
| `「＠台詞」` | これまでどおり話し手なし（モブ・喘ぎ。solo-story-kit.js などが `⁠` に置き換える） |

solo-story-kit.js の `ST.say` などは `「＠` を `「⁠` に置き換えるが、processText は `「⁠名前＠` の形も同じ目印として読む。
＠と＠の間は 16 字まで（句読点・空白・｜・「」を含まない）。

## 4. 使う側

- `view.js`（時系列）・`solo-story-kit.js`（物語型）：顔の並びの先頭を、台詞行（l）の最初の話し手にする（登場人物にいない話し手も先頭に出す）。
  吹き出し（`talk`）は、発話（l・q・m・u）があるときだけ（名詞の引用だけの記録は吹き出しにしない）。
- `core.js` の `HK.fmtLong(text, names, seg)`：seg を渡すと、台詞の塊を seg の `h` から取る。塊の決め方は `HK.fmtSpeech`・`HK.fmtMarkLine` にまとめ、
  seg を作るときも同じ関数を使うので、改行の結果は seg を使っても使わなくても同じ（seg-audit の fmt で確かめる。R18 版で 909 件の長い文がすべて一致）。
  名前の並びが seg を作ったときと違う（ダンジョンの表示の主など）・文が変わったときは、これまでの方法で改行する。
- `hakoniwa-tools/tone-check/collect.js`：名詞の引用かどうか（`nq`）を、自前の正規表現ではなく processText が決めた区分（`V._qKind`）から取る。区分 `kind` も記録する。
- `hakoniwa-tools/tone-check/seg-audit.js`：新しい点検（README を参照）。

## 5. 推定の改善（第1弾）

speakerOf（話し手の判定）と名詞の引用の判定に足したもの。

- 住人以外の人物の台詞を住人にしない：直前の文の主語が住人以外の人物（「〜人・〜師・〜長・村の〜・喋る猫・〜の方から声をかけてきた」、または人のしぐさ・話す動詞で終わる文。
  「村の年寄りたちが、一行を手招きした。「……」アキラは」「売れないバンドマンの方からアキラに声をかけてきた。「……」」）、「……」と村人が言った の形、「拡声器の声がした」。
- 住人の台詞が話し手なしにならない：「〇〇（名探偵）は、」の役割の括弧、「……」と、〇〇は／「……」と小さく呟いて、〇〇は、
  主語のない節（「〇〇は〜。それから口を開けて中を見せ、「27mlでした」と告げた」）、「〇〇の「……」に、」（名前の「……」はその人の台詞）、「「ありがとう」を連発」。
- 名詞の引用に足したもの：「と名づけ」「と呼ば」「だと」、台詞らしくない言い方の「〜」で・「〜」だ・「〜」。（「今回のデートは「図書館デート」。」「「ホテル・エトワール」で」）。

結果の指紋（regress.js）は、改善の前（区分の仕組みだけ）では r18・safe・全年齢版とも変える前と一致。改善のあとは、話し手・区分が変わった台詞の言い換えだけが変わる
（R18 版 6 回ずつで 45 記録。村の年寄り・魔術師などの台詞が住人の口調でなくなり、「〇〇の「どこ行く？」」が〇〇の口調になり、デートの行き先などの題名が言い換えられなくなった）。

## 7. 残っている誤りの型（次の担当向け）

R18 版 10 回ずつの u 314 件の内訳（目安）：

- 前の文の主語が住人以外の、名前のある人物・物（132）：「サチは、布団を敷きながら〜。「……」」「割り箸のくじが回ってきた。「王様だーれだ！」」。名前のあるモブ（サチ・大河内・トニーなど）は語の終わりで人と分からないので、目印 `「＠サチ＠……」` で直すのが確実。
- 前の文に主語がなく、2文前に住人（116）：「ミナトは顔を背けた。胃の奥がせり上がってくる。「…気分悪い」」。2文前まで見ると、モブの台詞を住人にする誤りが増えるおそれがあるので入れていない。
- 前の文に住人の名前があるが主語でない（46）：「ミナトの枕元に、一枚の紙が残されていた。「ありがとう。」」（置き手紙。c にしたい）。
- あとに住人の名前があるが形が拾えない（20）：「「くそっ」と吐き捨てた瞬間、ミナトの体が跳ねた」「「寒い……」と震えるミナトを」。

ほかに、登場人物（e.actors）に話し手が入っていない出来事（a1w）：エステの隣のブース、RPG の「〇〇は首を振った。「……」」、館の「ハルカは「今夜はやめておく」と断った」など。話し手の誤りではないが、顔の表示では話し手が先頭に足される。
