# 箱庭シミュレーター UI リデザイン — 実装仕様

- デザインキャンバス: https://claude.ai/artifact/Y6mHx21Xx7e9upK9eYnuPe （同じアカウントの Claude Code からは Artifact ツールで直接読めます）
- トークン: `design/tokens.css`（`index.html` の `<style>` 先頭の `:root` ブロックと差し替える）
- アートボード原本: `design/artboards/*.dc.html`（素の HTML＋CSS。クラス名・inline style をそのまま参考にできる）
- 前提: 既存の機能・JS 生成マークアップ・クラス名は維持し、CSS と一部のマークアップ構成だけを変える。

## 1. 配色の考え方

| 役割 | 値 | 備考 |
|---|---|---|
| UI の唯一の色 | 藍 `#16233B`（`--c`） | 文字・枠・主ボタン。濃淡は `color-mix(in srgb, var(--c) N%, var(--paper))` |
| 地 | 白 `#fff`（`--paper`） | 面の区別は罫線で行い、グレー面は 4〜9% の藍だけ |
| 補助文字 | 藍 68%（11px 級は 76%） | 白地で 4.5:1 を満たす |
| 罫線 / ボタン枠 | 藍 14% / 26% | |
| 重要の赤 | `#D7263D`（`--hot`） | 転機・情事・死亡にだけ使う。黒版は `#FF5C7A` |
| キャラのイメカラ | 既存の `--p0`〜`--p11` を維持 | アバターの輪と薄い面にだけ使う |
| 関係の色 | 既存値を維持（金 `#A97817` → `#4A5A9C` に変更） | 「フル」のときだけ有効 |

使わない色: 茶・金・橙系（旧 `--guard #A97817`、`--odd #A2420F`、警告の金）。影・グラデーション・絵文字も使わない。

### 黒版
`:root[data-theme="dark"]`（および `prefers-color-scheme: dark`）で `--paper: #0A0B0F`、`--c: #C9D4EC` に置き換えるだけ。混色が `--paper` を参照しているので他の変数は自動で追従する。ヘッダー右端に白／黒の切替ボタンを置く。

### 色の量（ユーザー設定・新規）
`:root` の `data-palette` に `mono` / `chars` / `full` を付け、`localStorage` に保存する。既定は `full`。

| 値 | 表示名 | 内容 |
|---|---|---|
| `mono` | 藍のみ | UI もイメカラも関係色も赤も藍一色。重要イベントは太字と大きな点だけで示す |
| `chars` | キャラ色 | UI は藍、アバターのイメカラと重要の赤だけ残す |
| `full` | フル | 関係タグ・関係図の線と凡例・時系列の重要タグにも色が付く |

ヘッダー右上に 3 分割のセグメントボタン（`藍のみ｜キャラ色｜フル`）を常設する。どのモードでも関係の種類は「塗り・輪郭・破線」で区別できるようにしておく（下記 4.）。

## 2. 文字

| 用途 | 指定 |
|---|---|
| 本文 | Noto Sans JP 14px / 400 / 行間 1.6 |
| ブランド | 22px / 700 / 字間 0.14em |
| 結果見出し | 28px / 700 / 字間 0.04em |
| 節見出し | 17px / 700 |
| ヒント | 12.5px / 藍 68% |
| 見出しの肩（Step 1 / Cast など） | IBM Plex Mono 11px / 字間 0.18em / 大文字 |

明朝（`--f-display`）は廃止し `--f-body` に統一。Google Fonts から Noto Sans JP と IBM Plex Mono を読み込む。

## 3. 部品

- 角丸 4px（`--r`）。チップのみ pill（999px）。
- ボタン: 高さ 36px、枠 藍 26%。主ボタンは藍の塗り＋白文字。ghost は枠なし・藍 68% の文字。スマホ幅ではタップ領域 44px。
- 入力: 高さ 36px、枠 藍 14%、フォーカスは藍 2px の outline。
- チップ: 高さ 28px、選択時は藍の塗り。件数は Mono 11px で右に添える。
- 工程タブ: 「1 住人 / 2 箱庭 / 3 経過と結末」を番号つきの丸で表示。選択中は藍の塗り、完了は薄い面。右端に「セーブ」。
- スイッチ（参加）: 34×20px、ON は藍の塗り。
- アイコンは inline SVG の線画（stroke 1.3〜1.5px）。絵文字は使わない。

## 4. 住人アバター（`.av`）

```css
.av { --k: var(--c); background: color-mix(in srgb, var(--k) 16%, var(--paper)); color: var(--k);
      box-shadow: inset 0 0 0 1.5px var(--k); border-radius: 50%; }
.av.inv  { background: var(--k); color: var(--paper); }       /* 反転 */
.av.bold { box-shadow: inset 0 0 0 3px var(--k); }             /* 太い輪＝生存して主導 */
.av.dash { border: 1px dashed var(--k); box-shadow: none; }    /* 破線＝離脱 */
.av.gone { opacity: .45; }                                     /* 不参加・死亡 */
.av.img  { overflow: hidden; box-shadow: 0 0 0 2px var(--paper), 0 0 0 3.5px var(--k); } /* 画像＋輪 */
```
`--k` にはキャラのイメカラ（`--p0`〜）を流す。画像アイコンは頭文字の代わりに表示し、外側の輪だけ残す。

## 5. 関係ラベル（`.lbl.*`）— 色がなくても区別できる形

| 種類 | 形（常に適用） | フルでの色 |
|---|---|---|
| 恋人 | 塗り＋白文字 | `--love` |
| 執着 | 塗り＋二重輪（`box-shadow: 0 0 0 2px paper, 0 0 0 3px 色`） | `--obsess` |
| 相棒 | 60% の塗り | `--partner` |
| 友人 | 薄い面（9%）＋藍文字 | `--friend` の 16% 面 |
| 片想い | 輪郭のみ | `--pine` |
| 守護 | 輪郭＋盾アイコン | `--guard` |
| 一夜 | 薄い面＋破線の輪郭 | `--night` |
| 敵対 | 破線の輪郭＋薄い文字 | `--enemy` |
| 殺害 | 塗り＋打消し線 | `--kill` |
| 変化なし | 文字のみ（藍 68%） | — |

関係図の線も同じ発想: 恋人・執着 3.5px 実線、相棒 2px、友人 1.2px、片想い 1.2px＋矢印、敵対 1.5px 破線（5 4）、殺害 2.5px 破線＋×、一夜 1.2px 点線（2 4）。フルでは線にも `--love` などを付ける。ノードの輪は太さ・破線でキャラの状態を表し、色はイメカラ。

## 6. 時系列

- 左 88px にターン番号（Mono 14px / 600）と局面名（11px 藍 68%）、右に 1 本の細いレール（左罫線）。各出来事はレール上の 7px の点。
- 通常の出来事は藍の単色。PHASE / CLASH / PAIR / LEAVE / END のタグは Mono 10px の藍 26% 枠だけで色を付けない。
- 会話は吹き出しをやめ、「」の引用文（500 ウェイト）と小さなアバターだけ。理由の補足は 12px 藍 68%。
- 転機・情事・死亡だけ `--hot`: レールの点を 11px の赤丸＋薄い赤の輪にし、ターン番号・本文（700）・タグ（赤の塗り＋白文字）を赤にする。補足文は藍 68% のまま。死亡は本文の前に `†`。
- 見出し横に「● 転機・情事・死亡」の凡例、絞り込みに「重要のみ」を置く。
- 概要数値の「転機 T07」、スパークラインの転機マーカー、組カードの該当ターンも同じ赤。

## 7. 住人タブ上部の整理（ボタンの列をまとめる）

### 方針
1. 毎回使う操作（追加・検索・絞り込み・並び・表示）だけを画面に残す。
2. たまに使うデータ操作（書き出し／読み込み／共有／文字列／保存フォルダ）は「データ」ダイアログ 1 つに畳む。
3. 同じ目的のボタンは 1 つにまとめ、説明文は 1 行にして詳細は「?」とメニュー内へ。
4. 「仲間とみなすグループ」は各グループ見出しのトグルに移す。

### 新しい構成
- 見出し行: 「住人 5 / 12 ?」＋ 1 行のヒント。右上に主ボタン「1 人追加 ▾」（split button）と「データ ▾」。
- 「1 人追加 ▾」のメニュー: 1 人追加 / 10 人追加 / ランダムで 1 人追加 ／ 質問に答えて診断して追加（25 問）/ 名簿を貼り付けて取り込む ／ 追加時の名前（おまかせ・空欄・番号）。
- ツールバー（1 本・上下罫線）: 検索（名前・メモ・グループ・タグ） ｜ グループの件数つきチップ（すべて N / 各グループ / グループなし） ｜ 並び select（登録順・グループ順・名前順） ｜ 折りたたむ／開くのアイコン 2 つ＋「50 人 / 頁」。
- グループ見出し: 折りたたみ矢印、グループ名、人数（Mono）、「仲間とみなす」トグル、右端に「このグループを箱庭に入れる」「名前を変更」。
- 「データ」ダイアログ: タブ「まるごと（別の端末へ）｜名簿・JSON｜保存フォルダ」。各ブロックはボタン 1 行＋説明 1 行。読み込み方のラジオは読み込みボタンの横。保存フォルダは「まだ選んでいません ／ フォルダを選ぶ」の状態行 1 本にし、Chrome の確認に関する長文は「?」へ。

### 旧ボタンの行き先
| 旧 | 新 |
|---|---|
| 1人追加／10人追加／ランダムで1人追加／質問に答えて診断して追加／名前：おまかせ | 「1 人追加 ▾」メニュー |
| まるごと書き出し／共有／まるごと読み込む／読み込み方／設定を文字列でコピー／文字列から読み込む／保存フォルダ | 「データ」ダイアログ |
| グループで絞り込む（select）＋札（押すと表示・非表示） | ツールバーの件数つきチップ |
| 登録順に戻す／グループ順に並べる | 「並び」select |
| すべて折りたたむ／すべて開く | アイコンボタン 2 つ |
| 1ページに 50人 | 「50 人 / 頁」select |
| 仲間とみなすグループ | 各グループ見出しの「仲間とみなす」トグル |
