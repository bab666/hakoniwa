# 喘ぎ・攻めの声の作り直し（設計書・2026-10-27）

R18版だけの話（全年齢版には入れない）。受けの「あっ、んっ」の単文が続きがちなのを崩し、攻めにも「言いかけて快感に遮られる」声、言葉責め・焦らしの台詞を持たせる。受けはそれにたまに言い返す。

決めたこと（利用者）：
- 気質は**態度9種のまま**書き分ける（強気・厳格・意地っ張り・穏やか・健気・冷静・奔放・恥じらい・敬語）。強気／甘えの2つに丸めない。
- 攻めに**言葉責め・焦らし**の枠を作り、主に夜の性格が**意地悪・サド**の人が使う。
- 受けは言葉責め・焦らしに**たまに言い返す**（「うるせえっ」「言わないでください……っ」「全部、あなたのせいです……あっ！」）。

## 4. 遮りの仕組み（`HK.Moan.cut`）

全部を手で崩して書かず、言い切る台詞をその場で崩す（`M.pound` と同じく部品から組む）。

```
HK.Moan.cut(S, who, line, lv, o) → 崩した台詞
  line … 口調の言い換えを通した「あと」の台詞（「」の中身）
  lv   … 1 少し（「……っ」を1〜2か所）／2 遮られる（喘ぎの切れ端を1〜2か所）／3 決壊（2〜3か所＋語尾を ！？・ッ に）
  o    … { sweet 甘い切れ端を使う（省くと態度から）, keepEnd 語尾を崩さない }
```

- **差し込む所**：読点「、」・「……」の後ろ、文節の切れ目（助詞「を・に・が・は・で・て」の後ろ）。印（`{男性器}` など・`＠名前＠`・`{名}`）の中と、最初の2文字の中には入れない。
- **差し込む切れ端**（`HK.MOAN_CUT`。態度9種で重みを変える）：
  - 強い切れ端（強気・厳格・意地っ張り・冷静）：`ッ`／`く……っ`／`ふ、っ`／`ぐ……`／`は、ぁ……っ`
  - 甘い切れ端（穏やか・健気・奔放・恥じらい・敬語）：`ぁ……っ`／`ん、ぅ……`／`〜〜っ`／`ふぁ……`／`っあ……`
  - 受けの言い返しの崩れ（a0〜a3 の lv3）：語尾の後ろに w0／w2 の声を一つ付ける（「全部、あなたのせいです……あっ！」）
- **順番**：台詞の3本を選ぶ → 口調の辞書（voice.js）で言い換える → **そのあとで** `cut` を通す（先に崩すと言い換えが当たらない）。崩したあとは言い換えを通さない印（`⁠`）を付ける。
- 敬語の人も崩れると敬語が剥がれる、は**崩す前の文**を3本の左（くだけた常体）から選ぶことで出す（lv3 のときだけ、敬語の人でも4割は左を使う）。

### 5-2. 受けが言い返す割合（「たまに」）
- 言葉責め・焦らしの直後に**3割**。一場面に**1回まで**。
- 堕ちている（`fallen`）受けは1割に下げ、a3（煽り返し）と a2 だけ。嫌がる場面では a0 を5割増し。
- 言い返しのうち半分は lv3 で崩す（「全部、あなたのせいです……あっ！」）。
- 受けが a3 で煽り返したら、次の攻めの声は**u5（煽られて崩れる）**に寄せ、快感の段を1段上げる。

### 5-3. 置き場所
- `EroTop.slots` が選ぶ段のうち、`fore`・`in`・`mid` に言葉責め・焦らし、`mid`・`peak` に u（崩れ）を置く。`thick-sex.js`・`r18-thick.js`・`solo-r18-moan.js` など `EroTop.say` を呼ぶ所は、`HK.Moan.tease` があればそちらを先に試す（無ければ今のまま）。
- 話し手は必ず `「＠名前＠…」` で固定する（受けの返しは前の文の主語が攻めなので、話者推定が取り違える）。

## 6. 守る決まり

- **攻めを選んだ人は受けにならない**：攻めの鍵（t・z・j・u）に受け身の言葉（奥・中に・ちょうだい・入れて など、今の `TOP_NG`）を入れない。逆に受けの鍵には「出す」「入れる」側の言葉を入れない。
- **3組すべてに専用文**（男×女・女×女・女攻め×男）：
  - u4（果てる宣言）は体で分ける：男性の体の攻め＝「出す」、女性の攻め＝「イく」「一緒に」（今の `CLIMAX_TOP_FF` と同じ考え方）。
  - z・u は体の組の表（`kind.m`・`kind.ff`・`kind.fm`）にも足す：女攻め×男は「動くな……っ、私が……ッ、動いてるん、だから……っ」の型、女×女は指や舌で責めながら崩れる型。
- **態度9種すべて**に書く。山場と喘ぎは態度9種で書き分け、1文だけで固定の段を作らない（1鍵につき1態度3本以上、z・a は4本以上）。
- 台詞（z・j・u・a）は**3本**「くだけた常体｜硬い常体｜敬語」、一人称「私」、二人称「あなた」。体の語は `{男性器}` `{女性器}` `{ナカ}` `{胸}` などの印。
- 喘ぎの基盤（t0〜t2 の上書き・t6・w2・w4・w5・e0）は `moan-said.js` と同じく、話し方を書かない素の言葉。
- 登場人物はすべて成人として扱う。
- 全年齢モード（`HK.SAFE_ON`）では何も出さない。新しいファイルはすべて**R18版だけ**に置く（全年齢版には入れない）。`js/_order.txt` は R18 の中核の、`moan-engine.js` の後ろに置く。

## 9. ♡のオンオフ（2026-10-30 追記・担当HT）

利用者の要望「男性向け表現にしつつ、ハート喘ぎのハートを取りたい」。♡は男性向けの作風の喘ぎ・台詞の表に直接書かれていて数が多い（ero-moan-tone.js だけで 135 か所）ので、文ごとに書き分けず、**出力の段階で、その話し手の♡を外す**。

- **設定**
  - 住人ごと：⚙設定「恋愛と夜」の「♡喘ぎ（男性向け）」（`c.heart`。既定はオン＝今までどおり。外したときだけ `false` を持つ）。攻めの声にも♡が付くので、受け攻めを問わず全員に出す（R18版だけ。印 r18 の中）。保存・読み込み・複製（`mk`）・JSON の書き出しと読み込み・設定の文字列コピーは濁点喘ぎと同じ経路（ui.js）。箱庭の入力には外したときだけ `heart: false` を渡す。
  - 全体：住人タブの「口調・喘ぎの設定」（対象「全体」）の「喘ぎ声の調整」の「♡の扱い」＝「住人の設定に従う（既定）／全員なし」。`HK.Moan.setFit` の `heart: 'off'`（moanfit に入るので、書き出し・まるごと書き出し・「足す」の読み込みにも乗る）。回すあいだは入口の設定に固定（`HK.Moan.heartAllOff()`）。全年齢モードでは効かない。
- **外す範囲**：性的な場面（`HK.lewdEvent`）の文と、喘ぎ（喘ぎらしい台詞・区分 m）だけ。ふだんの会話の口調の♡（「〜だよ♡」など）はそのまま。
- **外す場所と順番**（どちらも voice.js の `V.unheart`。二度通しても変わらない）
  1. `V.processText` の中（話し手が分かる台詞・埋まった発話）：口調の言い換え・書き下ろし・辞書・敬語化・仕上げ・性別の語尾・喘ぎの整え（`HK.Moan.fit`。濁点喘ぎの濁らせは、これより前の喘ぎのエンジン）・語尾の設定・二人称・呼び方のあと、**語尾の記号（`V.applyMarks`）の前**。♡で終わっていた文（記号を付けない）も、外したあとは記号が付く（「いい。♡もっと」→「いい♣もっと♣」）。
  2. voice-seg.js の最後の包み（e.seg を作ったあと）：区分ごとに外して e.text を作り直す。話し手のある区分（l・q・m・u で who があるもの）は話し手の設定、話し手の無い区分（地の文 n・名詞の引用 c・話し手の無い喘ぎ・モブの声・決まらない発話）は、**その場面の受け**（出来事の登場人物のうち攻めでない人。何人もいれば、この場面で喘いでいる人）が全員外していれば外す。受けが分からなければ外さない。
- **外したあとの体裁**：「あっ♡」→「あっ」／「……♡」→「……」／「♡♡」（続く♡・空白をはさんだ♡）→まとめて外す／「く、ぁ……♡　たまんねえ」→「く、ぁ……　たまんねえ」／「、♡」「。♡」→「、」「。」／「……♡……」→「……」／言葉のあいだの♡は読点（「すき♡すき」→「すき、すき」）／重なった句読点（「、。」→「。」）・二つ続く空白・台詞の頭と終わりの空白と読点（終わりの「、」は「……」）。外すと何も残らない・「っ」だけ・記号だけの発話は短い素の声（`V.HEART_VOICE`：ん……っ／あっ……／は、ぁ……っ／んぅ……っ。文から決まるくじ）に、一字だけの声（「あ」）は「あっ」にする。
- **点検**：`setting-audit.js` の `moan.heart`（外した人の性的な場面の台詞・喘ぎ・発話に♡が残らない割合。100%）・`moan.heartKeep`（相手の♡は残る）・`moan.heartAll`（全員なしで性的な場面の文に♡が残らない割合。100%）。設定が既定のままなら何も通らない（結果は前と同じ指紋）。
