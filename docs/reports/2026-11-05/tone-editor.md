# 口調の自作画面：置換が効いたり効かなかったりする件・語尾を足す書き方・見本の台詞で試す（2026-11-05）

## 利用者の指摘

1. 下のサンプル台詞が理想に近づくように置換してみても、ちゃんと置換できるときとそうでないときがある。
2. 「大丈夫」→「大丈夫だよ」のように語尾を足したいが、語尾の設定（かんたん）では「空欄＝だよ」が書けず、辞書に「大丈夫＝大丈夫だよ」と書くしかない（広い範囲の置換にならない）。
3. 「ござる」の見本が使いづらい。サンプル台詞をたくさん見ながら、その場で置換を試したい。
4. （追加の指示）サンプルはベース＝K・F・P 全てあった方がいい。

## 1. 原因（効いたり効かなかったりする理由）

見本の箱と実際の遊びは同じ経路（`HK.Ending.toneOf` → `voice.js` の `V.processText` → `tone-engine.js` の `T.pick`／`T.apply`）を通る。経路が違うのではなく、
辞書の当て方の決まりが画面から見えなかったのが原因。Playwright で再現して確かめた（下の「再現」）。

| 決まり | 起きること | 例 |
|---|---|---|
| **ベース（K／F／P）** | 台詞は「くだけた常体｜硬い常体｜敬語」の3本で書いてあり、住人の口調（語尾の設定・`ベース=`）で一本を選んでから辞書を当てる。選ばなかった文にしか無い語には当たらない | 穏やかの住人が `です=でござる` と書いても、くだけた常体の文に「です」が無いので一つも当たらない。欄の例（placeholder）にも `ベース=P` が無かった |
| **文末は終わりまでそろったときだけ** | [文末] は文の終わり（。！？の手前）で、元の語が最後までそろったときだけ。一文に一つ、長い項目が先 | `です=でござる` は「いい天気**ですね**」「本当**ですか**？」に当たらない |
| **長い項目が先** | 口調の辞書（その住人の口調の組み込みの辞書）にある長い項目が、書いた短い行より先に当たる | 敬語の住人の「〜ですよ」に、組み込みの `ですよ=…` が先に当たる |
| **語彙で置き換えた語のあとには文末を重ねない** | [語彙] で置き換えた語が文末にあると、[文末] は当てない | `ありがとうございます=かたじけない` のあと `ます=まする` は当たらない |
| **不自然になる文には当てない** | 問いに言い切りの語尾・強い文（！）・あいさつの語尾・重い台詞の勢いの語は、候補を外して元のまま | 「ありがとう」の文末の書き換え |
| **くじと言い切り** | `／` の候補・言い切り（たまに・よく、辞書の `言い切り=0.2`）は台詞ごとのくじ。同じ設定でも台詞によって元の形のまま | 見本の箱が数秒ごとに一行ずつ替わるので、当たった行と当たらない行が交互に見えた |
| **辞書を当てない台詞** | 敬語で話す相手への台詞（敬語のまま）・喘ぎ／とっさの短い声（ベースの口調で整える）・「〜」という引用 | 敬語の相手を決めている住人で、その相手への台詞だけ辞書が効かない |
| **頭の「〜」** | `〜です=〜でござる` は、文の中に「〜です」が無いので当たらなかった（語尾の設定の欄は「〜」を外していたが、辞書は外していなかった） | |

書き下ろし（tone-fix）が辞書より優先される件：語尾の設定・辞書を使う住人の口調は `e:…` の鍵になり、書き下ろしの表に行が無いので、ふだんの台詞では当たらない
（喘ぎ・短い声だけベースの口調に戻るので、そこでは書き下ろしが当たる）。

### 再現（Playwright。`HK.ToneLab.run`・`explain`）

- 穏やか＋`[文末] です=でござる／ます=まする`：見本の 44 行で当たり 0。
- 敬語＋同じ辞書：「いい天気ですね」「どこで買ったんですか？」「もう寝ますか？」などが元のまま（文の終わりが「ですね」「ですか」「ますか」）。
- 語尾の設定「だよ」：「大丈夫。」「座って。」「怖い。」は元のまま（名詞・て・形容詞で終わる文は語尾（ふだん）の型に無い）。

### 直し方：理由を画面に出す

- `tone-engine.js`：`T.trace` が配列のときだけ、語彙の置き換え（当てた・当てなかった理由）・文ごとの文末の項目（当たった項目・不自然で外した・語彙の後ろ・言い切りで落とした・短い文はため口）を記録する。
  `voice.js`：`V.trace` が配列のときだけ、台詞の経路（辞書・1本の辞書・書き下ろし・敬語の相手・喘ぎ・引用）とベースを記録する。どちらもふだんは `null` で、出力は変えない（regress 一致）。
- `ui-tone-lab.js`（late）：見本の台詞を一行ずつ言い換え、記録から「当たった行」と、書いた行（辞書の [文末]・[語彙]）が当たらなかった理由を利用者の言葉で出す。
  同じ文に書いたほかの行（長い「ですね」など）や語尾の設定が当たっていれば、短い行の「当たらない」は出さない（足りているので）。
  辞書に「です・ます」の行があるのにベースが敬語でない住人には、一覧の上に「辞書の頭に『ベース=P』と書きます」と出す。

## 2. 語尾を足す書き方

**選んだ形：語尾の設定（かんたん）に「文末に足す」の欄、口調の辞書（上級）では [文末] に `=だよ`（元を空にした行。`文末=だよ`、[規則] の `文末に足す=だよ` も同じ）。**

理由：利用者が試したのが「空欄＝だよ」という書き方だったので、辞書ではそのまま書けるようにし、かんたんの欄にも同じものを一つの欄として出す（どちらも同じ規則 `append` になる）。
「大丈夫=大丈夫だよ」のような 1 語の置き換えは今までどおり動く（見本の 31 行目で確かめた）。

決まり（`tone-engine.js` の `appendEnd`。文末の項目がどれも当たらなかった文だけ）：

- 問い（？）・言いよどみ（……・ー・〜・っ で終わる）・短い間投詞・あいさつ（ありがとう・ただいま・ごめん…）・倒置（似合ってるよ、その服）には足さない
- もう終助詞・敬語・言いさし（よ・ね・な・さ・の・か・から・けど・です・ます・ください…）や助詞（に・を・が・は・と）で終わる文、同じ語尾で終わる文には足さない
- 「だ」で始まる語尾（だよ・だぜ・でござる・なのだ）は、名詞の後ろはそのまま（大丈夫だよ）、動詞・形容詞・て形の後ろは「だ」を外す（分かったよ・怖いよ・座ってよ）。「〜だ」で終わる文は「だ」と入れ替える（そうだ→そうだよ）。「〜んだ」「〜のだ」には足さない
- 言い切りの規則で語尾を落とした文には足さない。`／` で候補を並べるとくじ

既定の口調・既存の設定には `append` が無いので、結果は変わらない。

## 3. 見本の台詞で試す（画面の構成）

置き場所：⚙設定の「口調」では語尾の設定（かんたん）の下、住人タブの「口調の設定」では口調の辞書（上級）の下（折りたたみ。開いたときだけ言い換える）。
読み込み前（late）は出さず、口調の辞書（上級）の中の今までの見本（9 行）を出す。読み込んだあとは、同じ台詞を二度並べないよう辞書の中の見本は出さない。

- 見本の台詞：`ui-tone-lab.js` の 44 行（日常・あいさつ／感謝・謝罪／怒り・ケンカ／照れ・恋愛／弱音・気遣い／問い・相談。全部 3 本の台詞）。R18版は全年齢モードでないとき夜の台詞 4 行（45〜48。r18 の印の中なので全年齢版には入らない）
- 道具の帯：種類（すべて・6 種・夜）／「別の例」（12 行ずつ次へ）／全部出す／**3本のベースを並べる**（既定は入）／言い換える前の文（既定は入）／当たった行・理由（既定は入）。表示の切り替えは、このブラウザに覚える
- 一行の中身：番号、3 本のベースの段（くだけた常体・硬い常体・敬語。同じ文のベースは一つの段にまとめる）。各段に「言い換える前の文 →『言い換えたあと』」と、その段で当たった行（辞書／語尾の設定／口調の辞書の札つき）。
  この住人が使う段に★と左の線。★以外の段は「そのベースだったら」の見本（`T.forceBase`。見本の箱だけが使う）。その下に、★の文で当たらなかった書いた行と理由（赤字・4 件まで）
- **表示の形の選び方**：3 列にすると幅 390 で一列が 100px ほどになり読めないので、段を縦に重ねる（PC もスマホも同じ）。★の段は濃く、ほかは薄く。台詞の一覧は高さ 60vh まででスクロール
- 入力のたびに描き直す：語尾の設定・辞書・一人称などの欄の入力 → `VS.sampleRefresh`（ui-voice.js）→ `HK.ToneLab.refreshAll`（300ms 待って、開いている箱だけ。スクロール位置は保つ）

辞書の見本「ござる（侍）」は、見本の台詞に当たる行から並べ、各行に「見本 ○ 行目」のコメントを付けた（番号は全年齢版にもある 1〜44 だけ）。「〜だよ（語尾を足す）」の見本も足した。
