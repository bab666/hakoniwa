# 妊娠は体の関係の場面のあとだけ（2026-11-07）

## 報告
オメガバース（R18版・展開の重さ「重い」・内容のスイッチ「妊娠・孕む描写」）で、βの男性が発情期のΩの女性の部屋の前に食料と飲み物を一週間分置いていく出来事（看病）のすぐあとに「孕んだかもしれない」の段が出て、のちに妊娠が分かり、結末でも出産していた。

## 原因
- `content-events-r18.js` の `pregHook` は、記録の `HK.sexEv(ctx, o).sex` が真なら孕む描写を差す。`actRun`（engine.js）は結果に `sex` が無ければ定義の印 `sex: true` を記録に渡すので、定義に `sex: true` のある出来事が体の関係にならない枝（看病・拒む・耐える）を返しても「体の関係」の記録になっていた。
- `om_heat`（scenario-omega.js の `heatScene`）の 4 つの枝（番以外を拒む・αが理性で耐える・βの看病・Ω どうしの共感）と、それを包む `omega-love.js`（回数の目安で抑制剤と看病で乗り切る）・`omega-secret.js`（恋人・番への操で踏みとどまる）が、`cat: 'help'` だけで `sex: false` を返していなかった。

## 直し方
1. 出来事の側：体の関係にならない枝の結果に `sex: false` を付けた（両ビルド）。
   - scenario-omega.js `om_heat`（heatScene）：番のいるΩが拒む／αが理性で耐える／βが看病する／Ω どうしの共感
   - omega-love.js `om_heat` の包み：抑制剤と看病で乗り切る
   - omega-secret.js `om_heat` の包み：恋人・番への操で踏みとどまる
   - omega-passion.js `om_steal`：恋人への想いで踏みとどまる（cat: conflict）
   - scenario-room.js `speedrun`：振り向きざまに手首を掴まれてかわされる（cat: conflict）
   - room-trio.js `trio`：三人でを強く拒む（cat: conflict）
2. 妊娠の側（受けの安全弁）：`pregHook` は、分類が help の記録には差さず、その組の夜の印（`pf.night`・`pf.nights`）がその出来事の中で増えたとき（オメガバースはこれだけ）か、ほかの箱庭ではエロシーンの印 `e.lewd` があるときだけ差す。「その出来事の中で」は act() が出来事ごとに作り直す `ctx._touched` で見分ける。体を重ねた組の登録（`sexP`）も同じ条件の後ろに置いたので、終わりに足す描写（`pregFill`）と結末の「その後」も情事のあった組だけになる。
3. 保存済みの記録は書き換えない。新しい点検は足していない（下の数字は scratchpad の道具で一度だけ計測）。
