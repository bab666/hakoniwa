## 0-2. 土台は合意（利用者の指示 2026-11-07・2 回目）

利用者の言葉：「あくまで今までと同じ箱庭のフィクションであるのと、いずれも合意でないように見えて、実際は二人の愛憎を楽しむための、あくまで合意的な展開に持っていくための箱庭になります。より濃くしろとはいわないので、他の箱庭で実現できているレベル（監禁や非合意展開など）に合わせて、言い方や表現を少しずつ変えて実装してください。ユーザーからはやや合意でなさそうに見える、というところは保ちたいです」。

これを 5 部屋の決まりにする：

- **濃さは本体の今の水準に合わせ、越えない**：本体に既にある、執着の監禁の夜（`obsess-kit.js` の ob_cage_night）・敵対の二人の強引な場面（`hate-sex-r18.js`。口では嫌がるが流される swept／最後まで拒む refuse）・恐怖の相手に迫られる夜（`cold-fear-r18.js`）・合意のない展開の回数の書き分け（`force-repeat-r18.js`）と同じ濃さ・同じ構え（`dark-thick.js` の「甘く書かない・♡を使わない」）。言い回しを部屋ごとに変えるだけで、描写をこれより濃くしない。内容のスイッチ（合意のない展開・死・妊娠）と展開の重さは本体の決まりのまま読む。
- **二人の土台は合意**：どの部屋も、受け側は「望んでここにいる・望んでいる」側の気持ちを持つ（**本音の計器 `want`**：上がるだけ。始まりの値は関係と設定から：執着を受け入れている（`HK.Obsess` の accept／mutual）・愛憎・両片想い・恋人・体の相手 なら高く、片想い・友人・元恋人は中、不仲・知らない人は低いが 0 ではない）。R18 の場面は **`want` が部屋の線を越えている二人にだけ**起き、越えていなければ心理劇の段（言葉・鍵・鎖・見つめ合い）で止まる。きっかけの段には、受けが止められたのに止めなかった一文（鍵は開いていた・逃げる足が止まった・「嫌」と言いながら手を離さなかった）を必ず入れる（表面はためらい・拒む言葉のまま。これが「やや合意でなさそうに見える」の部分）。
- **薬**：監禁の「薬」は受けが差し出された杯を自分で飲む形（眠り薬は眠らせるだけで、眠っている間の行為は書かない。媚薬は本体の媚薬ロッカーと同じ扱い＝体が火照る）。ストーカーの「薬を盛って」は、狙われる人が気づいていて寝たふりをする（眠りの部屋と同じ土台）か、起きて迎える形に書き替える。
- **眠り・認識阻害**：眠る側・される側は、前もって「寝ている間なら」「いつ使うかは言わないで」と許している二人（恋人・体の相手・両片想い）か、途中で気づいて寝たふり・気づかないふりを選ぶ人。昼の分岐（違和感を探る・寝たふり・自分から誘う）はその「ふり」の遊び。何も知らないまま終わる結末は、受けが先に許していた二人にだけ。
- **調教**：奴隷側は契約（借金・興味・相手への想い・自分で望んだ調教）で地下室に来た人。お披露目会のモブへの奉仕は、契約で先に決めてある範囲だけ。心は折れず解放・愛情に変わる・立場の逆転 の結末は、土台の合意から自然に出る。
- **ストーカー**：狙われる人は、相手が誰か気づいている（元恋人・両片想い・振った相手・気になっていた人）か途中で気づく。撃退・トラウマの結末は性的な場面なしで終わる形。誘拐後の場面は、狙われる人が「取り込まれる」分岐のときだけ。
- **三組の体の決まり・態度 9 種・表情・巻き戻らない計器・点検**は 0 章のまま。

## 2. 共通部品 HK.DarkKit（kit）

**名前**：本体の `HK.Dark` は展開の重さ（mood-dial.js、かたまり pack-sim）がもう使っていて（`HK.Dark.on`・`pick` など）、上書きすると本体が壊れるので、kit は **`HK.DarkKit`**（部屋では `var DK = HK.DarkKit;`）にした（2026-11-07 第 1 段で変更）。kit は文を持たない。書き方の例は `hakoniwa-packs/set-c/WRITING.md`。

### 2-1. 巻き戻らない計器・表・記録（kit-dark.js）
- `DK.gauge(S, name, { v, min: 0, max: 100, dir: 'up' | 'down', stages: [しきい値…], label })` → 計器 `{ v, min, max, dir, stages, label, stageMax }`（`S.gauges[name]`）。同じ名前が既にあれば作り直さずに返す。`up` は上がるだけ（値 ≥ しきい値で 1 段）、`down` は下がるだけ（値 ≤ しきい値で 1 段）。`v` の既定は `up` なら min、`down` なら max。
- `DK.push(S, name, delta)` → `{ v, d（実際に動いた量）, stage, rose（段が上がったか） }`。逆向きの delta は 0 に丸める。無い計器は例外。一時の揺れ（薬が切れて少し戻る）は計器ではなく `S.tmp`（区切りの初めに `DK.tmpReset(S)`）。
- `DK.val(S, name)` → 今の値。`DK.stage(S, name)` → 到達した最高の段（`stageMax`）。
- `DK.stOk(st, n)` → 段の札 `'2'`・`'2+'`・`'-1'`・`'1-2'` が段 n に合うか。
- `DK.pick(ctx, S, list, o)` → 文字列（`o.full` なら行。無ければ `''`／`null`）。行は文字列か `{ t, st, sh, when(ctx, S, a, b), w }`。`st` は空白区切りで並べられ、`'名前:2+'` はその計器の段、名前の無い札は `o.stage`（数）か `o.g`（計器の名前）の段で見る。`sh` は `o.sh`（mf／ff／fm）と合わない行を外す。`when` が偽の行を外す。`w` は重み。一回の遊びで同じ文を二度出さない（`S.used`）。使い切ったら `o.again` のときだけ、使った回数が少なく古いもの（`S.lru`）から戻す。`o.a`・`o.b` は `when` に渡す。
- `DK.once(S, key)` → 初回だけ真。`DK.seen(S, key)` → もう出たか。`DK.use(S, t)`・`DK.fresh(S, t)` → 表を通さない文を使った印にする・まだ使っていないか。
- `DK.who(t, i, why)`・`DK.mark(t)`・`DK.fill(ctx, t, a, b, ex)`：セット B の `HK.PairKit` の写し（話し手の目印「＠{x}＠」を付け、ex と {a}{b} を当てる。全年齢の ♡ の置き換えは無い）。
- `DK.say(ctx, o)` → 記録（出なければ null）。`ctx.act2` に o を渡し（`id`・`tag`・`face`・`S`・`t`・`a`・`b`・`ex` は kit が読む）、`e.ev = o.id`・`e.tag = o.tag`・`e.dkf = o.face`（`{ 住人の番号: 鍵 }`。喘ぎの鍵は外す）を付ける。`o.t` と `o.a`・`o.b` を渡せば `fill` してから出す。`o.S` を渡せば本文を使った印にする。本文に作り手の語（`DK.NG`：計器・段の札・分岐・ゲージ・stage・gauge・`{x}` の残り・undefined・NaN）があれば出さずに `ctx._dkLeak` に残す（部屋の計測で 0 を確かめる）。`e.fc` は本体（voice.js）が台詞の頭の印から作るので kit は触らない。

### 2-2. 役と可否・重さ・スイッチ・揺らぎ（kit-dark-cast.js）
- `DK.per(c)` → 態度 9 種（`HK.Emo.att` か `HK.personaOf`。無ければ `gentle`）。`DK.PER` が 9 種の並び。
- `DK.pOdd(ctx)` → らしくない分岐の確率（`ctx.chaos` × 0.32、0〜0.45。セット B の `HK.PairReact.pOdd` と同じ）。`DK.branch(ctx, c, table, keys)` → `{ k, odd, per }`（`table` は `{ 態度: 分岐, _: 既定 }`。揺らぎのときは keys のうち既定でないものから等分）。
- `DK.part(ctx, c, field)` → 住人ごとの欄の値（`'auto'`・空は null）。
- `DK.cast(ctx, { field: 'part', top, bottom, others: [...], auto(ctx, X, Y) → [A, B] })` → `{ A, B, G, noBody, why }`。上の二人（立場で選んだ人を先に、周りの値の人は後ろ）から、立場で A・B を決め、両方おまかせなら `auto`（無ければ上の人が A）。
- `DK.noBody(A, B)` → 体の場面を出さない理由（`'topIsBottom'`：A が自分で受けを選んだ＝`!HK.Pos.canTop(A, B)`／`'bottomIsTop'`：B が自分で攻めを選んだ＝`HK.Pos.hardTop(B, A)`／`'body'`：`HK.bodyOK(A, B)` が偽＝恋愛対象・性行為の相手の固定・R18 にしない相手）。空なら体の場面を出してよい。`cast` の `noBody` はこれが空でないとき真（部屋は `S.noBody` に写し、開始前の注意 `HK.SoloWarn.add` でも伝える）。設計の `HK.Pos.isBottomOnly` は本体に無いので `canTop` で読む。
- `DK.couple(field, top, bottom, others)` → `couple(C, input)`（`DK.install` に渡す二人を選ぶ関数）。
- `DK.install(ID, couple, endKey, { outside, guest: 'guest', field: 'part' })` → `{ outsideOf, withOutside, strip, trim }`。`HK.simulate` を `HK.wrap` で包み、`outside` が偽でなく設定 `env.outsideNames` が `'no'` でなければ名簿から二人のどちらかと関係のある住人を三人まで周りの人として足し（欄 field に guest、印 outside）、結果から外す。`r.end[endKey] = ctx.flags[endKey]`。セット B の `HK.PairCast` の写し（なれそめの上書き override は無い）。
- `DK.heavy(ctx)` → `mild`／`normal`／`dark`（`env.heavy` が空なら `dark`）。`DK.heavyDefault(ctx)` → 部屋の setup で呼ぶと、空のとき `env.heavy = 'dark'` にする。
- `DK.content(ctx, key)` → `HK.Content.ok(ctx, key)` の包み。**利用者の内容のスイッチどおりで、kit は上書きしない**（設計の初版にあった `forceAlways`（部屋の側で force を常に真にする）は kit に入れていない。題材として常に入の部屋を作るなら、本体の `HK.Content.CORE` と同じ扱いを部屋の担当とまとめ役が決める）。

### 2-3. 場面の組み立て（kit-dark-r18.js。第 1 段では作っていない。別の担当）
