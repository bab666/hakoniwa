# 名前の呼びかけを「ここぞ」に絞る（2026-11-01 担当NC）

利用者の依頼：「今はたまに名前を呼びかけるときの台詞に違和感があるので、名前の呼びかけは『ここぞ』というときになるよう減らしたい。全体の箱庭を見渡してブラッシュアップ」

## 1. 呼びかけの出どころ

| 経路 | どこで | 今回 |
|---|---|---|
| 自動の差し込み | `js/tone-plus.js` の `V.callAddress`（`voice.js` の台詞の仕上げから呼ばれる）。呼び方を決めた相手（敬称の設定 `call`・相手ごとの呼び方 `calls`）への台詞の頭に「〇〇、」を足す | 「ここぞ」の文だけに絞り、頻度を下げた（2 章） |
| 二人称の置き換え | 同じ `V.callAddress`。文の「あなた」「お前」を、呼び方を決めた相手の呼び方にする | そのまま（利用者の設定どおりに呼ぶ仕組み） |
| 手書き | 各箱庭・共通の出来事の台詞に書かれた `「{b}、…」` `「……、{a}」` など | 約半分を落とした（3 章） |
| 口調の書き下ろし | `tone-fix*.js`・`tone-brush*.js`・`voice-override*.js` で、元の文の「〈〉って」「〈〉は」を「〈〉、」にしていた行（176 本） | 人狼・館の名指しの推理（呼びかけとして自然）は残し、軽い行 15 本だけ「〈〉って」「〈〉は」に戻した。手書きで名前を落とした台詞の書き下ろし（鍵が元の台詞の行）は、鍵と中身から同じ所を落とした（両ビルドで 137 行） |

宇宙船の手書きの文（`ship*.js`・`ship-crisis.js`・`special.js`）は別の担当が同時に変えているので今回は触っていない（別途）。自動の差し込みの変更は宇宙船にも効く。

## 2. 自動の差し込みの規則（tone-plus.js・voice.js、両ビルド同じ）

- **足してよい文（「ここぞ」）**：台詞のどれかの文が次の形のときだけ（`V.kokozo`。返事・相づちで始まる台詞は除く）
  - stop 引き止め・制止：最初の文の最初の読点までが「待って」「行かないで」「やめて」「止まれ」「離さないで」…（「止めてほしくなったら」「やめておけ」は除く）
  - attn 聞いてほしい：最初の文の頭が「聞いて」「こっちを見て」…
  - warn 警告：最初の文が「危ない」「逃げて」「伏せろ」「離れろ」…（今までの CALL_WARN）
  - plea 懇願・救助：「お願い（、）」「頼む」「助けて」「死なないで」「しっかりして」「そばにいて」…（「よろしくお願いします」「〜でお願い」は除く）
  - confess 告白：「好きだ」「ずっと、好きだった」「愛してる」で終わる文
  - anger 怒り：「許さない」「ふざけるな」「いい加減にして」「どういうつもり」
  - farewell 別れ：「さよなら」「元気で」「忘れないで」「また会おう」
  - rescue 名指しの気づかい・問いただし：「大丈夫か」「大丈夫？」「無事か」「怪我は」
  - talk 「話がある」
- **足さない文**：ふつうの頼み・誘い・命令（「こっち来て」「手伝って」「行こう」）、返事・相づち・説明、短い台詞（記号を除いて 10 字以下）、喘ぎ（♡・小さい母音・っ、）
- **頻度**：「ここぞ」の文でも台詞ごとに決まった **四つに一つ**（前は三つに一つ・命令や誘いの文すべてが対象）。二人きりの出来事（登場人物 2 人）はさらに半分（**八つに一つ**）。
  指示書の目安は六つに一つだったが、計測すると「ここぞ」の文は台詞行の約 0.2%（R18版 1 箱庭 8 回で 6367 行中 13 本）しかなく、六つに一つではほとんど出なくなるため四つに一つにした
- **場面の決まり**：同じ記録（場面）では一人一度まで（前から）。**ひとつ前の記録で同じ相手を呼んでいたら足さない**（voice.js の `V._callLast`・`V._callPrev`。文にもとからある呼びかけ・二人称の置き換えも「呼んだ」として覚える）
- **R18**：性的な場面の記録（`HK.lewdEvent`）では、懇願（plea）・告白（confess）だけ。喘ぎの表の `{名}`（moan-engine.js の呼び方）は別の仕組みで、今回は触っていない（`V.callAddress` は♡・小さい母音の台詞に足さないので重ならない）
- 足した台詞は記録に `e.callAdded`（数え上げない属性。保存・表示には出ない）として残し、点検が経路を分ける

## 3. 手書きの呼びかけの見直し

- 洗い出し：台詞の頭の `「{x}、` `「＠…＠{x}……` と、台詞の中・終わりの `、{x}」` `。{x}、`（名前の印でないもの（`{you}` `{like}` `{item}` `{m1}` など）・宇宙船・special.js は除く）
- 数（R18版の js、宇宙船・special.js 以外）：**422 → 189（55% 減）**。全年齢版：**181 → 103（43% 減）**（全年齢版には R18 の多いファイルが無い）
- 直したファイル：文のファイル R18版 39 本（うち全年齢版にもある 26 本は同じ変更。約 230 行）＋口調の書き下ろし 31 本（R18版。全年齢版にあるものは同じ変更。約 110 行）
- 3 本の台詞はそろえて直した（どのベースでも同じ所を落とす）。R18 の文は印の中のまま、文の中身だけを変えた

### 残した（「ここぞ」）例

- 告白：「{a}、恩人としてじゃなく、{a}のことが好きだ」（room-tie.js）・「{o}……ずっと、好きだった……っ」（locker-tie-more-r18.js）

## 4. 点検：call-audit.js（audit-all.js の既定の一式に入れた）

`node hakoniwa-tools/tone-check/call-audit.js <ビルド> [回数=8] [r18|safe|''] [箱庭,…] [--why]`。audit-all.js ではパス `call`（1 箱庭 8 回）。

- 配役：seg-audit と同じ名前・口調の回し方・種。住人の敬称の設定を「おまかせ・呼び捨て・さん・おまかせ・くん・ちゃん」で回し、3 回に 1 回は 1 人目に相手ごとの呼び方を付ける（自動の差し込みは呼び方を決めた相手にだけ働くため）
- 数えるもの：台詞行（e.seg の l・q）のうち、住人の名前・呼び方で呼びかけている台詞の割合（参考の表示）。経路（自動・二人称の置き換え・手書き）ごと
- 違和感の型（件数。0 が目標）：dup（同じ記録で同じ相手を 2 回以上）・short（名前を除いて 8 字以下）・reply（相づち・返事）・explain（説明の言い切り）・solo（一人の記録で居ない相手）・pair（二人きりで毎回）・honor（敬称の重なり）・mob（モブの名前）。
  名前だけの呼びかけ（「……ミナト」）・重い場面（死・処刑・最期・弔い・再会・別れ）・「ここぞ」の言葉の台詞は数えない。「〇〇さん、ですよね」（人の確かめ）・「〇〇、人狼」（結果）・「偽物は、〇〇」は呼びかけに数えない
- 閾値：audit-all の回数（1 箱庭 8 回）ではすべての型が 0 になったので、閾値は置いていない（`TH = {}`）。1 箱庭 24 回では 0 にならない分が残る（下の表。挨拶「〇〇さん、ちわっす」・R18 の「お前、わざとだろ」の二人称の置き換えなど）
