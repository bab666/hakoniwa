# キスの描写の型（HK.Kiss）とキスだけの触れ合いの場面（設計・2026-11-03）

利用者の指示（趣旨）：

- キスの描写のパターンを沢山増やす。
- キスだけの触れ合いの場面を、エッチとは別に用意して盛り込む（サドの人がキスでお預けにするのもかわいい）。
- 短〜長で汎用の描写の型を作る。
- 新婚なら「いってらっしゃいのキス」、それが盛り上がって名残惜しくなる、という感じ。

## 1. ファイル

中核（core）は増えていない（build の「中核の中身の増減なし」）。R18版の HK.Kiss を pack-lewd に置いたのは、エッチの入り方「キス」がどの箱庭（一人用の箱庭も）でも同じ文になるように（pack-rel は一人用の箱庭では読まないので、置くと読み込み順で結果が変わる）。全年齢版にはエッチの型が無いので pack-rel。

## 2. 型の軸

| 軸 | 値 | 文 |

| 三人 | 三人目に見られる（冷やかし 4・妬く 4）・三人のキス 4 | 12 |

文は合わせて 372 本。台詞は 3 本「くだけた常体｜硬い常体｜敬語」（一人称「私」・二人称「あなた」・敬語のベースに尊敬語・謙譲語を書かない）、名前が二人出る段の台詞は「＠名前＠」。`{a}`＝主導する人（受け攻めの攻め。`HK.Pos.order`）・`{b}`＝受ける人。受けがねだる・迫る（おねだり・袖を引く）はあるが、唇を寄せるのは攻め。お預けの文は「口づけ」「唇を重ね」「キスをし」を使わない（出られない部屋の条件「キス」に数えられないように）。不仲の版も同じ。

## 3. 選び方（`HK.Kiss.plan`）

| 入力 | 効き方 |
|---|---|
| きっかけ | いってらっしゃいは短いが基本（短い 75%・中 17%・長い 8%）。おかえり・おやすみは中くらいも多い。雨宿りは長いも多い |
| 攻めの夜の性格（R18 だけ。全年齢は none） | 甘々 → 長い ×2.5・もう一回・名残惜しい。恥じらい → 短い ×1.8・照れて離れる。サド・意地悪 → 中くらい ×1.3、お預けが 45%・40%（ほかは 5%、強気・奔放は 10%）。からかいのきっかけは +30% |
| 態度 9 種 | 受けが恥じらい・意地っ張り → 照れて離れる。受けが健気 → もう一回・名残惜しい。恥じらいの二人は短く。受けの反応・攻めの一言・お預けの台詞は態度で選ぶ |
| 気分（HK.Emo） | どちらかの喜びが高い → 長い ×1.5。受けの恥ずかしさが高い → 短い ×1.3 |
| 関係 | 恋人・夫婦（箱庭の恋人・関係）＝ふつうの型／両片想い＝初めてのキス／友人＝事故のキス・じゃれ合い（恋愛の出来事ではない）／不仲＝にらみ合い（キスしない）。家族などの「恋愛：なし」・無関心・恐怖には出さない。文は `HK.relFilter` で関係に合うものに絞る |
| 呼ぶ側 | `opt.trig`・`len`・`end`・`place` で固定。`opt.night`（R18 でそのまま夜へ）・`opt.promise`（続きは帰ってから）・`opt.oazuke`（お預けに足す値）・`opt.long`（長い版の倍率） |

一回の遊びの中では、同じ文を二度出さない（`ctx._kissU` に使った回数を覚え、いちばん使っていない文から選ぶ）。乱数は ctx.rng。

### 計測（R18版・恋人の関係 0-1・恋愛の起こりやすさ 90・12 回。重みを決めたときの見当）

重みの 1/2.5 のとき、無人島 12 回で 7 件・出られない部屋 12 回で 4 件・クラスメイト 12 回で 17 件（出来事全体の 1〜2%）。上の重みはその 2.5 倍。

## 5. エッチの入り方「キス」（R18版）

`HK.PlayText.ENTRY.kiss` の 3 組（mf・ff・fm）に、型の文で組んだ段を 6 本ずつ足した（ついばむ段 STEP.peck ＋ 濃い段 STEP_R18.deep ＋ 攻めの一言 A_LINE。乱数を使わない決まった組み合わせ）。入り方の最後の攻めの台詞は、エッチの型の仕組み（`entryLines`）で同じ入り方の台詞から選び直される。文は「脱がせる」「体位」の言い回しを書かない（着衣の型・流れの管理と矛盾しない）。

## 6. 新婚部屋（追加パック set-b・shinkon-kiss.js）

shinkon.js は書き換えず、`HK.wrap` で次の 4 つを包む（まとめ役の新しい shinkon.js（三人婚つき）とも同じ包み方で合う）：

| 包む関数 | 差し込むもの |
|---|---|
| 箱庭の `phase`（区切り） | 朝の区切りのあと：いってらっしゃいのキス／夜の区切りの前：おかえりのキス／日中の区切りのあと：ご褒美のキス／最後の夜の区切りの間だけ、幸せなキスの文の表（`HK.ShinkonText.KISS`、三人婚は `HK.ShinkonTrio.T.KISS`）を型の長い版に差し替える |
| `HK.Journal.add`（願望の高まり） | 夜の区切りで最初に呼ばれたとき（仲直りのあと・願望の行動とエッチの前）：仲直り・ごちそうさま・おやすみのキスのどれか一つ／三人婚で三人とも家にいる夜は、ときどき三人のキス |
| `HK.ShinkonR18.night`（R18版の夜） | 朝の「続きは帰ってから」・おやすみの「そのまま夜へ」があった夜：起こりやすさを上げ、きっかけの段（理由が「きっかけ：」の記録）の頭に朝の約束・キスの続きの一文を置く（理由に「（朝のいってらっしゃいのキスの続き）」「（おやすみのキスから）」） |
| 箱庭の `finish` | 結果の記録 `flags.shinkon.kiss` にキスの回数（計測用。画面には出さない） |

- いってらっしゃい：その日、仕事で出かける人（出張でない・休日でない・日中に家にいない）がいる朝の 75%（どちらかが恥じらい・厳格なら 60%）。体調を崩した日・出張で離れている日・治った朝・まだだるい日は出さない。三人婚は出かける人と家にいる人から一組
- おかえり：出かけた人が帰りの遅くない夜の 35%（朝に約束した夜は 75%）。その夜に困りごと（残業・電車・雨・停電など）がある夜は出さない。R18 で朝に約束した夜は短く名残惜しく終え、続きは夜のきっかけの段へ
- ご褒美：二人とも家にいる日中（休日 20%・平日 6%）
- 夜：喧嘩して仲直りした夜は 55% で仲直りのキス、夕飯の夜は 22% でごちそうさま、ほかは 30%（約束の夜は 15%）でおやすみ。最後の夜は出さない（幸せなキスがあるので）
- 最後の夜の幸せなキス：今までの幸せなキスの文（10 種 × 2 本）を始まりの段にして、型の長い版（重ねる → 深い → 息が上がる → 名残惜しい／抱きしめて終わる）を続け、「二人は幸せなキスをした。」で結ぶ
- 看病の部屋には入れていない（まとめ役が後で頼む）

### regress（読み込み順を変えたので）

変える前（HEAD）の指紋を基準に、キスの出来事を止めた版（`HK.KISS_OFF = true`：出来事の when が偽になるだけで、乱数の流れは変わらない）と、ふつうの版を比べた（N=6）。

| | キスを止めた版で基準と違う箱庭 | ふつうの版で基準と違う箱庭 |
|---|---|---|
| 全年齢版 | なし | 合コン・出られない部屋・クラスメイト・無人島・バトルロワイヤル・裁判デスゲーム・ゾンビの街・オメガバース（キスの出来事のあるエンジン型の箱庭だけ） |
| R18版の全年齢モード | 無人島（下の「ついでに直したもの」の誘いの台詞の言い換え） | 合コン・出られない部屋・クラスメイト・無人島・ゾンビの街・オメガバース |
| R18版 | 合コン・出られない部屋・オメガバース（エッチの入り方「キス」に型の段を足した・下の「ついでに直したもの」） | 合コン・出られない部屋・クラスメイト・無人島・ゾンビの街・オメガバース |

### ついでに直したもの（乱数の流れが変わって表に出た、前からの崩れ）

- play-text-r18.js：主な責め「言葉責め」（女攻め×男）の前戯の「手首を掴んでどけた」が、入り方「我慢できずに」などの手首の動きと二度出しになる（sex-flow (c)）→「腕をそっとどけた」
- ero-initiative-r18.js：受けの主導の導入の文（態度ごと 3 本）を皆で一つの覚えで回していたため、ほかの住人が使い切ると同じ人に同じ導入の台詞が二度出た（sex-flow (f)）→ 住人ごとに覚え、台詞のある文はほかが尽きるまで戻さない
- moan-said-more.js：「なんで、こんな……っ♡　いい、んだよ……っ」が、意地っ張りの男性の口調で「いい、のよ」になる（moan-tone-audit）→「くそ、ぉ……っ」
- grief-kit.js（両ビルド）：バトルロワイヤルの弔いの場所「茂みの奥」が「茂みの奥まで連れ出した」で性的な文の点検に当たる（state S15）→「茂みの陰」
