# 新婚部屋（Bセット 見本）の設計（2026-11-03）

利用者のソロジャーナル（表を振って二人の一日を書く遊び。表とプレイログの例は利用者からの提供）を、箱庭の型に移す。
**遊んだあとに「プレイログ」のような記録が残る**のが要。日々の暮らしの中で、二人それぞれの願望（願望pt）が高まり、10 の倍数を越えるたびに願望の行動が起き、
R18版ではそれがエッチのきっかけにもなる。最後は幸せなキスで一区切り。

## 0. 置き場所

| 置き場所 | ファイル | 中身 |
| --- | --- | --- |
| 本体（新しいかたまり `pack-roomkit`。追加パックの部屋が選んだときに読む） | `js/roomkit-life.js` | `HK.Life`：仕事の型・家庭での役割（生活の state）と、その日の在宅・帰りの時間・出張の判定と一言 |
| 〃 | `js/roomkit-journal.js` | `HK.Journal`：願望pt（10 の倍数の越え）・表を引く（一回の中で同じ行を続けない）・プロンプトの記録の行・日ごとの記録（結末の「二人の記録」） |
| 追加パック `hakoniwa-packs/set-b/` | `js/shinkon-data.js` | 利用者の表（シーン導入・日替わり・キーアイテム・結末・ご飯・願望行動・幸せなキス・喧嘩・酔っ払い・特別な日・なれそめ・住まい）と、各行の地の文 |
| 〃 | `js/shinkon.js` | 箱庭の本体（設定・一日の流れ・結末） |
| 〃（R18版だけ。行全体を r18 の印で挟む） | `js/shinkon-r18.js` | ちょっとえっちな日替わり・きっかけ（自慰の目撃を含む）・プレイの内容・反応（受け向け・攻め向け）・事後の反応と、短い／中くらいのエッチの場面 |

部品（HK.Life・HK.Journal）は B セットのほかの部屋（看病・夜のドライブ・デートの日々）でも使う。

## 1. 設定

### 環境（箱庭の設定）
- 日数：5〜14日（既定7日）。1日は「朝・日中・夜」の3区切り。
- 二人の住まい（住まい表の10＋おまかせ）、二人のなれそめ（関係性表の10＋おまかせ）、出会いの場所（偶然の出会いの表の10＋おまかせ）、季節。
- 願望の溜まりやすさ（ゆっくり・ふつう・早い）。
- R18版：エッチの回数（少なめ＝1回／ふつう＝1〜2回／多め＝2〜3回）。

### 住人ごと（参加者の欄）
- 仕事の型（生活の state）：外回りが多い／社畜気味（残業が多い）／定時で帰る／在宅ワーク／自営業／出張が多い／夜勤・シフト／専業（家事が中心）／おまかせ。
- 職業（自由記入・任意。例：営業、看護師、イラストレーター）。地の文に出す。
- 家庭での役割（家庭での役割表の10＋おまかせ）。
- 願望（願望表の10＋おまかせ＝気質から）。初期の願望pt は表のとおり。

## 2. 一日の流れ（1区切りごとに記録を残す）

| 区切り | 記録に出るもの |
| --- | --- |
| 朝 | 「〇今日のプロンプト」（シーン導入表・日替わりイベント表の結果。必要に応じてキーアイテム・ご飯・特別な日）。シーン導入の地の文 |
| 日中 | 仕事の型ごとの一言（出張・在宅・残業など）。日替わりイベントの地の文（キーアイテム・ご飯を織り込む） |
| 夜 | 「〇願望pt」（増えた分）。10 の倍数を越えた人の願望行動（その願望の行動表から）。R18版はエッチの場面（きっかけ→場面→事後）。シーンの結末表の地の文。「〇ふたりの距離」の一行 |
| 最終日の夜 | 幸せなキス（幸せなキスの表）。ここで一区切り |

- 願望pt：日ごとにシーン導入・日替わりで 1〜6、「ムラムラしている」は 1〜10 増える。願望に合う出来事は多めに増える。10 の倍数を越えるたびに願望行動を1つ（同じ行動は一回の中で二度出さない）。
- 仕事の型は在宅（家にいる区切り）と日替わりの選ばれやすさに効く（出張の日は離れて過ごし、連絡の出来事が増える、など）。家庭での役割は家事・料理の出来事の書き分けに効く。
- 喧嘩のきっかけ表・困ったときのリアクション表・酔っ払い表は、日替わりの結果に合わせて差し込む。

## 3. R18版のエッチ（1回の遊びで 1〜3 回）

- **入口**：ちょっとえっちな日替わりイベント（夜の区切り）／願望「もっとエッチなことがしたい」の願望行動／ほかの願望が高まったとき（沢山スキンシップ・独り占め・深く愛されたい）／**自慰を目撃して**（きっかけ表 ♦8 の専用の流れ）。
- **形**：短い場面（きっかけ・プレイの内容・事後の反応）と中くらいの場面（きっかけ・前戯の反応・プレイの内容・攻めの反応・山場・事後の反応）を混ぜる（おおよそ 6：4）。
- **直前に必ず「きっかけ」の段**（なぜ今エッチになったか。願望pt・その日の出来事・誰が言い出したか）。
- 守ること：体の関係にしてよい組だけ（`HK.State.pairSex`・`HK.sexBlocked`・`HK.ngSexPair`・`HK.canLove` を両方向）。受け攻めは `HK.Pos.order`。形は 男×女（mf）・女×女（ff）・女攻め×男（fm）で書き分ける。体の語は印。山場と喘ぎは態度9種（共通の部品を使う）。合わない組はキス・添い寝までにする。

## 4. 結末

- 幸せなキスの一文のあとに「二人のN日の記録」：住まい・なれそめ・仕事の型、最後の願望pt、願望行動の回数、喧嘩と仲直り、エッチの回数（R18版）、いちばん幸せだった日。
- 結末の上に二人の表情の差し込み口（data-face）。

## 5. 文の決まり

- 利用者の表の行は、そのまま「プロンプト」の記録に出す（遊び方の記録として読める）。地の文はそれを場面にした文で、1 行につき 2 本以上。
- 台詞は 3 本のベース（くだけた常体｜硬い常体｜敬語）、一人称「私」・二人称「あなた」。名前は {a}・{b}。
- 全年齢版には R18 の文を入れない（shinkon-r18.js は行全体を r18 の印で挟む。全年齢版のパックの組み立てで落ち、性的な語が残れば止まる）。
- 点検：audit-all（既定の一式）・relcons・tone-feel（全口調 3% 以下）・base-lint・catalog-check。出来事には表示名を付ける。
