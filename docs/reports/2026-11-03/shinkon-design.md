# 新婚部屋（Bセット）の設計（2026-11-03・利用者のフィードバックで作り直し）

もとは利用者のソロジャーナル（表を振って二人の一日を書く遊び）を箱庭の型に移したもの。フィードバック（`shinkon-feedback.md`）を受けて、
**表は「何が起きたか」の種として内部で引くだけ**にし、記録の行（〇プロンプト・〇願望pt）・「〜表」「プレイログ」の語は画面に出さない。
展開（受け止め方・反応・決着）は、本体の箱庭と同じく性格・関係・らしくない行動で変わるようにした。

## 1. 設定

### 環境
- 日数 5〜14（既定7）。1日は朝・日中・夜。
- 二人の住まい・出会いの場所（おまかせか選ぶ）。
- **二人のなれそめ**：既定は「元の関係のまま」。住人の関係（友人・擬似親子・同僚など）をそのまま使う。関係が無い・恋人や夫婦の関係なら新婚の夫婦（`extraTies` で夫婦の関係を足す。恋愛にしてよい二人だけ）。
  ほかを選ぶと二人のあいだの関係を外して夫婦にする（`HK.simulate` を包み、入力の写しで動かす。家族などで恋愛が「なし」の関係は上書きしない）。設定の説明に【注意】として書く。
  結婚していない二人（元の関係のまま・恋人どうしの関係でない）には「結婚・新婚・夫婦」の文を出さない（`WED`）。恋愛にならない二人には恋愛の文を出さない（`ROM`）。
- 願望の高まりやすさ。
- **他の住人を出す**（既定：出す）：参加者の三人目から（住人ごとの「立場」で「他の住人」にした人）が、新婚の二人のどちらかと関係（家族・擬似親子・友人・同僚・同級生・元恋人・知人）があれば訪れる。
- R18版：エッチの回数（少なめ／ふつう／多め＝一度は長い場面）。**描写の有無・長さ・作風はほかの R18 の箱庭と同じ共通の設定**（`HK.Lewd.install`。長さの既定は「混ぜる」）。体の語の選び分け（lewd-words.js）も同じ値を読む。
- 本体の共通の設定（運命の揺らぎ・恋愛の起こりやすさなど）もそのまま効く。

### 住人ごと
- 立場（新婚の二人／他の住人。おまかせは上から二人）・仕事の型・職業・家庭での役割・願望。
- 役割「家事をしているが得意ではない（ポンコツ）」の人がいるときだけ、ポンコツの出来事を引く。
- 役割「忙しい仕事人」「ヒモタイプ」の人は家事・料理をしない。ご飯は料理をする人が作り（`HK.Life.cookOf`）、いなければ外食・出来合い・別々の種だけ。
  地の文・受け止め方・夜の文の候補は、文の中で家事・料理をしている人（その節の主語）が家事をしない人なら外す（`HK.Shinkon.choreOk`）。

## 2. 一日の流れ

| 区切り | 出来事 |
| --- | --- |
| 朝 | シーン導入の文（その朝の気持ち）。朝ご飯。朝の困りごと（寝坊・コーヒー・勤務のすれ違い） |
| 日中 | 仕事の型ごとの一言。日替わり（主役の性格で種の選ばれやすさが変わる）／休日のデート／ポンコツ＋**受け止め方**（相手の態度9種。揺らぎでらしくない反応）。喧嘩。日中の困りごと。他の住人の訪れ（休日は遊びに来る・出かける） |
| 夜 | 夜の困りごと（焦げ・残業・電車・雨・家電・鍵・停電・虫・買い忘れなど）＋受け止め方＋決着（気質で。言い合いなら夜に仲直り）。昼・夜ご飯。連絡・訪れ。仲直り（謝るのは性格で）。願望の行動（＋相手の受け止め方）。R18版の夜。一日の終わり（ふたりの距離の一文を添える） |
| 最終日の夜 | 幸せなキス（恋愛にならない二人は明日の話） |

- 区切りごとに本体のエンジンも動く（`actRate` 0.2、平日の日中は 0.08）。共通の出来事（関係ごとの出来事・らしくない行動 unl_*・日常の小さな出来事）が混ざる。
  体の関係の出来事・合意のない展開・三人以上の恋愛・告白・夫婦の関係の出来事（危険な場面を前提にした文があるため）は外す。
- 他の住人は出番の外では留守（`gone`）。出番の出来事のあいだだけ場に出す（共通の出来事に混ざらない）。

## 3. R18版の夜

- 入口（きっかけ）：ちょっとえっちな出来事／日々の気持ちの高まり（きっかけの表）／ひとりでしているところを見て／**ゴムを買いそびれた夜（受けの態度9種のおねだり）／遅く帰った夜／雨に濡れて帰った夜／停電の夜／出張から帰った夜／来客へのヤキモチ（元恋人は専用の文）**。
- 長さ：ほのめかす（描写の有無「ほのめかす」）／短い（種の文。作風「男性向け」なら `HK.ThickEro.short`）／中くらい（反応・山場の喘ぎ＝態度9種）／長い（本体の `HK.ThickSex.scene`・`HK.ThickEro.scene` に家の寝室の始まりと事後の反応を渡す）。濃い＝もう一度（`HK.ThickEro.again`）。
- エッチ多めなら最初の一回を長い場面にする（描写の長さ「数行で短く」以外）。
- 直前に必ず「きっかけ」の段（記録の一件、理由「きっかけ：…」、e.tag＝'きっかけ'）。
- 体の関係にしてよい組だけ（`HK.State.pairSex`・`HK.sexBlocked`・`HK.ngSexPair`・性欲「なし」）。受け攻めは `HK.Pos.order`。ヤキモチで妬いた人が受けのときは、押さえつける文を使わない。

## 4. 結末

- 幸せなキス。「二人のN日」：住まい・関係（なれそめ）・出会い、仕事と役割、願望、願望の行動・困りごと・喧嘩・来客・エッチの回数、いちばん心に残った日。pt の数字は出さない。

## 5. 文の決まり・点検

- 台詞は3本（一人称「私」・二人称「あなた」）。話し手は `HK.ShinkonKit.mark` が目印を付ける（同じ文の「{x}は／が」、前の文の主語、「と{x}が言った」、受け身は相手）。決めにくい文はソースに「＠{x}＠」を直に書く。
- 点検：audit-all（`HK_PACK_CODES`・`HK_ONLY_SCEN=set-b-shinkon`、追加パス relcons・sexgate・name・state-hot・group）・tone-feel（49 口調 3% 以下）・base-lint（`hakoniwa-packs/set-b`）。
  ほかに、話し手の目印の無い台詞・家事をしない人の家事・エッチのきっかけの付き方・関係に合わない文を数える小さな確認を回した（作業メモ。0 件）。
- 出来事の印：`@event`（朝・日中・夜・デート・ポンコツ・願望・ご飯・困りごと 17 種・訪れ・祝福・ヤキモチ・夜の入口 9 種・夜の長さ 4 種）。
