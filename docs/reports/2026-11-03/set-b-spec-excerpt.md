# セットB（ふたりのイチャイチャセット）の仕様の抜き書き

仕様書（Claude Docs「新規箱庭セット 仕様書」）から、残りの部屋の表（役・環境ダイヤル・性格で分かれる行動・山場・結末）と部屋の作り方の節を写したもの（2026-11-03）。各行の並びは「部屋名／役（選べる関係）／環境ダイヤル／性格で分かれる行動／山場／結末」。

## 部屋の作り方（仕様書の節）

```
部屋の元にする型
元の型
今の箱庭
この型で作る部屋
日常型（日数・朝昼夕夜で進む）
ふたりの日常
新婚・看病・夜のドライブ・ふたりの日常・デートの日々・子どもに戻った相手のお世話・監禁・贖罪・ストーカー
段階型（理性や堕ちの段を踏む）
媚薬ロッカー・催眠
調教の地下室・媚薬の湯の旅館・眠りの部屋
ソロ型（一人＋モブ・仕掛け）
常識改変・サキュバス・催眠（solo-kit）
触手の研究所・AV撮影・修道院・痴漢電車
企画型（司会と企画で進む）
エロバラエティ
お昼のバラエティ
大勢型
出られない部屋・クラスメイト・無人島・裁判デスゲーム・オメガバース
俳優パロ・ドムサブ／ケーキバース・法廷・マフィアパロ・ハーレム部屋・雪山の山小屋
部屋の表（一部屋につき一つ）
部屋は「元の型」と次の表だけで登録できるようにする（部屋の登録を抽き出した共通の入口を作る）。
始まりの状態：関係・役（監禁する側など）・日数。
環境ダイヤル：設定画面の欄と、どの出来事の重みに効くか。
行動の選択肢：気質からの選ばれ方（fit）と、その行動の出来事。
4幕の出来事：導入・展開・山場・着地に出てよいものと、必ず出す山場。
結末：判定の条件、届かなかったときの一行、図鑑のヒント。
部屋の小道具：エッチの型に足す入り方・道具・終わり方。
書く文と任せる文
部屋ごとに書く：きっかけ、行動の出来事、山場、結末とその後、部屋の小道具の入り方。
共通に任せる：エッチの山場・喘ぎ・体位（ThickSex・R18M・Thick4・DarkThick）、気分の句、食べ物、関係ごとの反応。
台詞は最初から「くだけた常体｜硬い常体｜敬語」の3本で書き、口調は辞書に任せる。体の語は印で書き、両方の版にあるファイルの性的な文は r18 の印で挟む。
作業の分担
共通部品3つと部屋の登録の入口を先に作り、今の箱庭の結果が変わらないこと（指紋の一致）を確かめる。
セットごとに見本の1部屋を完全に作り、点検を0件にする。
残り4部屋を、見本と指示書を渡して Opus の担当に並行で書いてもらう（一担当一部屋）。指示書には書式・出来事の印・きっかけの登録・点検の名前を必ず書く。
まとめて build・点検・一覧の更新をして、セットごとに一つのコミットにする。
```
