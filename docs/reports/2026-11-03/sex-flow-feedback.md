# 長いエッチの場面の流れの不整合（利用者のフィードバック 2026-11-03）

## 利用者の報告（原文の趣旨）
新婚部屋（追加パック）の長い場面で、本体の共通の組み立てが出した流れ。
- 居間のソファで始まり、ローリッツ（受け）が「今夜は、私のおそばにいていただけますか」と誘う。
- ハオン＝ドル（攻め）が「敷布へ転がし」「誰が起きていいって言った？　今夜は、こっちが決める」。
- 指で焦らす段のあと、**また**「乱暴にベッドへ突き倒し」「誰が起きていいって言った？」（同じ台詞・同じ動きが二度出る）。
- 受けが「服をはだけられるたびに腕で体を隠そうと」（挿入のあとに脱がせる段）。
- 受けが「このまま私にお任せください」と上に乗って主導する段のすぐ次に、「ハオン＝ドルはローリッツの両手首を頭の上で押さえつけたまま、真上から最後の一突き」（体位が変わったのに流れが戻る）。

## 利用者の指摘
1. 同じような台詞・動きが繰り返し出る。
2. 乗っかったはずの受けが、すぐ真上から押さえつけられるなど、展開が変わりすぎる。体位を変えるときは不整合になりやすいので、全体で直せそうなら調整する。
3. **エッチの流れを段階的に管理すべき**：攻めが射精するまでの性感、受けが達するまでの性感、今の段階（前戯・挿入・プレイの内容・体位を変えるかどうか・体位を変えたなら変えたあとの流れ・達する）。
4. 言葉責めや「気持ちいいと言え」のような台詞のあとに、リアクションが無いまま進む。淫語を言わせるプレイには、ちゃんとリアクション（受けが言う／言えない／抗う など、態度で変わる）を挟む。
