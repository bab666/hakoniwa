# 喘ぎの口調の不整合（2026-11-03）

利用者の報告：「喘ぎ声が指定の口調どおりにならず、強気の口調なのに女口調になっていたりする不整合が多発している」。

## 仕組み（喘ぎの選び方のおさらい）

1. `HK.Moan.pick`（`hakoniwa-full/js/moan-engine.js`）が鍵（w1・b0・h1 など）で声を選ぶ。言葉のある声は **態度 9 種の基盤**（`moan-dict.js`・`moan-said*.js`）か口調の表（`ero-moan-tone.js`・`novel-moan-tone.js`）から。
2. 基盤の態度は `psOf`：**夜の性格**（サド＝強気・マゾ＝健気・意地悪＝奔放・甘々＝穏やか・恥じらい＝恥じらい）があればそれ、なければ口調から（エゴグラムで決まる口調はエゴグラム）。
3. 最後に `fit`（口調・性別に合わない語尾を整える）を通す。

## 原因

- **強い口調の人にも、夜の性格やエゴグラムで健気・穏やか・恥じらい・奔放の基盤が当たる**（マゾの強気、甘々の厳格、エゴグラムが健気のヤンキーなど）。基盤の言葉は「止めないで」「もっと、して」「イっちゃう」「ちょうだい」「だめなの」「とけちゃう」のような女性的・甘えた形。
- `fit` の「はっきりした口調」の直しは、**拒みの形**（やめて→やめろ、いや→むり）と「〜のよ・〜かしら」しか見ておらず、お願い・甘え・女性的な言い切りが素通りだった。熱血（hero）は「はっきりした口調」に入っておらず何も直らなかった（不整合の割合が最も高かった：14%）。
- 恥じらい・健気の基盤の敬語（「イきます」「〜ください」）が、敬語でない口調の人にも残ることがあった。
- 無口の「すきぃ」「とまってぇ」「いいわ、そこ」も同じく基盤の形のまま。
- 既存の点検（`moan-audit.js`）は夜の性格を付けずに回し、規則も拒み・女性的語尾だけだったので 0 件と出ていた。

## 直し方（`moan-engine.js` の `fit`）

- 熱血を「はっきりした口調」（FIT_FIRM）に入れた。
- `strongFit`：基盤の言葉はそのままに、語尾だけ口調の形にする。区分は rough（強気・兄貴分・ヤンキー・熱血）／stiff（厳格・冷静・論客・無機質 など）／grand（紳士・尊大）／god（神）／noja（のじゃ）。
  - 〜ないで → 〜るな（rough は 〜んな。grand は 〜ないでくれたまえ、noja は 〜るでない）。五段は語幹から終止形を作る（抜かないで→抜くな、離さないで→離すな、止めないで→止めるな／止めんな、しないで→するな、来ないで→来るな）。
  - もっと、して → もっと、しろ（grand は してくれたまえ、noja は してたもれ、god は せよ）。来て→来い、入れて→入れろ など。
  - ちょうだい → くれ（grand くれたまえ、god よこせ、noja おくれ）、イっちゃう → イっちまう（rough）／イってしまう（そのほか）、〜だもん → 〜だ、だめなの → だめなんだ（noja のじゃ、grand・god のだ。問いは 〜のか）。
  - 伸ばした甘え（〜てぇ・〜よぉ）を戻す（`unLong`）。
  - 直さないもの：後ろに「くれ・もらえる・ほしい」が続く頼みの形（「見ないで、くれると……」「して……くれ」。二重の頼みにしない）、問い（「どこ、触って……」）、「勝手に、動いて」。
- 敬語でない口調（敬語の口調・敬語まじり・関西弁・のじゃを除く）は、敬語の基盤を `kForm` でくだけた形に（KFORM に「くださ」「ちゃいます」「イきます」の途中切れを追加）。
- 無口：`quietFit`（伸ばした甘え・ちょうだい→ほしい・いいわ／だめなの→いい／だめ）。息の「……ふぅ」「う、うぅ」は直さない。
- 紳士の付け替えで「まっしろ」の「しろ」を命令と取り違えて「まっしたまえ」にしていたのを直した。
- 「山場の台詞」（喘ぎの表にない、言い換えを通る台詞。light）は甘えた語尾だけ直す（台詞のお願い・言い切りは書いた形のまま）。
- `strongFit` の出力は `--why` の例で目で確かめた（引き継ぎで見つけた崩れ：「見るな、くれると」「してくれたまえ、くれたまえ」「どこ、触ってたもれ」→ 直した）。

## 道具の使い方（`hakoniwa-tools/tone-check/moan-tone-audit.js`）

```
node hakoniwa-tools/tone-check/moan-tone-audit.js hakoniwa-full            # R18版の全箱庭（約 9 分）。0 件で終了コード 0
node hakoniwa-tools/tone-check/moan-tone-audit.js hakoniwa-full 2 --tones=gentleman,noja --why   # 口調を絞って例を出す
HK_PACK_CODES=DDDD-EEEE-FFFF HK_ONLY_SCEN=set-b-shinkon node hakoniwa-tools/tone-check/moan-tone-audit.js <試し>/hakoniwa-full 4 --scen=set-b-shinkon
                                                                            # 追加パック（build/pack-site.js で作った試しのフォルダ）
node hakoniwa-tools/tone-check/moan-tone-audit.js --json=a.json hakoniwa-full ; node ... --from=a.json --why   # 集めた喘ぎに規則だけ当て直す
```

- 集め方：moan-audit.js を夜の性格ごと（なし・サド・マゾ・意地悪・甘々・恥じらい）に回す。作風（男性向け・小説調）・濃さ・性別の並びも回ごとに変わる。
- 規則：lint.js の MOAN_RULES（moan-audit の (a)）に、強い口調の女性的な語尾・甘えた語尾・弱いお願い、敬語でない口調の敬語、無口の女性的な語尾・伸ばした甘え・長い声、一人称の取り違え、頼みの形の二重、付け替えの崩れを足したもの。
- 出力：規則ごと・口調×性別ごと・夜の性格ごと・基盤の態度ごとの件数と例（`--why` で出どころ）。

## 誤検出の扱い

規則の側で直したもの：「こんなの、」「気持ちいいの、」（名詞）は女性的な言い切りに数えない、「しろよぉ」のような崩れた命令の伸ばしは数えない、のじゃの「じゃ」を「〜ちゃう」と取り違えない、「勝手に、動いて」・「どこ、触って……」（問い）・後ろに「くれ・もらえる・ほしい」が続く頼みは弱いお願いに数えない、無口の息（「……ふぅ」「う、うぅ」）は伸ばした甘えに数えない。引き継ぎの時点の規則で数えた誤検出は 0 件になるまで規則を直した（直した後の 0 件は誤検出を除いたものではなく、当たりが無い）。

## 範囲の外

- チャラい・ダウナー・意地っ張り（強気でない中性的な口調）の「イっちゃう」「止めないで」は、その口調の味として数えない。
- 強い口調の崩れた叫び（「むりぃ」「すごいぃ」）は、山場で声が崩れるものとして残す。
