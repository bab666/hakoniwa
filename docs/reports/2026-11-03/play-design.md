## 3. 組み立て（`P.apply`）

本体が出した本文の中の、本体の表の文（前戯 `T.FORE`・`X.FORE`、繋がる段 `T.BODY`・`ROUGH_BODY`・`JEALOUS_BODY`・`FM_BODY`・`FF_BODY`…、果てる段 `T.CLIMAX`…・`X.CLIMAX`…）の場所を探し（喘ぎの差し込みは正規表現でまたぐ）、型の文に置き換える。

1. 同じ役割の部品を外す：能動性の型（ero-initiative-r18.js）の体位を変える段（型の体位に置き換える）。性格が目立つ行為の段を足すときは、攻めの夜の性格の一文（attr-r18.js。受けの夜の性格・相手に合わせる人の一文があるときは残す）。
2. 着衣（chakui）：本文全体から「脱がせる」文を外す（外すと段が空になる・主語が無くなるときは着衣をやめて「無し」に）。
3. 入り方の段を前戯の前に置く（夜の主導の段がある夜は置かない＝entry 'lead'）。
4. 前戯の段 → 主な責めの前戯（道具の一文＋責めの地の文＋受けの崩れ方＋受けのこらえる声）。前戯に付いていた「指を抜く」一文は外す（流れの管理が要るときに付け直す）。
5. 繋がる段 → 型の体位の繋がる段。続けて最中の段（「そのまま、」＋体位の動き＋責めの一文＋道具の一文）と、性格が目立つ行為の段（下の 5）。
6. 果てる段の文 → 終わり方の文（受けの果てる声はそのまま）＋道具の事後の一文。
7. 本体の「感じていく」段の地の文の後ろに、受けの態度の崩れ方（MID_B）を一文。

組み替えた段（入り方・前戯・繋がる段・最中・終わり方）は守る段（`keep`）として `F.fix` に渡す：段数の上限に数えず、外さない（挿入の前へ移すのはよい）。

### 流れの管理との整合（sex-flow-r18.js）

- 型の体位の段のあと山場までは体位を固定：別の体位を前提にした言い回し（b）は、つなぎの段で戻さず、その一文（なければ部品）を外す。
- 新しい点検 (h) 型の矛盾：着衣の型なのに脱がせる／型の体位の段のあと（山場まで）に別の体位へ変える動き（女性の攻めが腰を落とす言い回しはどの体位でも使うので数えない）。`F.check(units, mode, play)`・`F.analyze(…, play)`。
- 体位の文は `HK.SexFlow.POS.chg` が読む言い回しで体位を作り（kijo は「{b}を…腰の上へ跨がらせ」、zai は「膝の上に抱き上げ」など）、繋がる言い回し（`RE.insert`）を必ず含む。終わり方の文は体位の言い回しを書かず、山場の言い回し（`RE.climax`）を「止め」「堪え」など山場でない印と同じ文に置かない。
- 一回の遊び（シミュレーション）のあいだ、型の文・流れの段の文は使った文を覚えて避ける（`HK.SexFlow.memo`。全部使ったら前に使ったものから戻す）。本体の表は従来どおり `HK.Ero.fresh`。

## 7. 部屋ごとの専用の長い場面（`P.addScene`）

追加パックの部屋（看病の部屋など）が「その部屋でしか出ない長い場面」を登録する入口。長い場面（`HK.ThickSex.scene`・`HK.ThickEro.scene`）が呼ばれたとき、`ctx.input.scenId`（`opt.ctx`・`opt.S`）がその部屋なら、`when` が真の場面から重み（`weight`。型の候補 1 に対する重み）で選び、入り方・前戯・繋がる段・最中を場面の文にする。山場の喘ぎ・終わり方・事後は共通の部品のまま。流れの管理（`HK.SexFlow`）の段階に沿って並べ、守る段として扱う。

```js
/* @event scen=set-b-kanbyo id=kanbyo-water cat=夜 tie=- tags=night label=水をこぼした服を脱がせるうちに */
HK.Play.addScene('set-b-kanbyo', {
  id: 'kanbyo-water', label: '水をこぼした服を脱がせるうちに',
  when: function (ctx, a, b, opt) { return !!(ctx && ctx.S && ctx.S.sick); },  /* 出す条件（省くといつも候補） */
  weight: 2,                                                                       /* 型の候補 1 に対する重み */
  play: { prop: 'none', pos: 'zai' },                                               /* 固定したい軸（省いた軸は選び方に任せる） */
  lead: { mf: ['…きっかけの段（3 文以上）…'], ff: [...], fm: [...] },              /* 入り方の段の代わり＝きっかけの段 */
  steps: [
    { stage: 'undress', mf: ['濡れた服を脱がせる段…'], ff: [...], fm: [...] },      /* 前戯の段の代わり（undress・fore は順に並ぶ） */
    { stage: 'fore', all: ['…'] },
    { stage: 'insert', mf: ['…繋がる段（体位は play.pos と合わせる）…'], ... },     /* 省くと型の体位の繋がる段 */
    { stage: 'play', mf: ['…最中の段…'], ... },                                    /* 省くと型の最中の段 */
    { stage: 'after', all: ['…終わり方のあとに足す一文…'] }
  ],
  tags: ['night']
});
HK.Play.addRoom('set-b-kanbyo', { entry: { nekomi: 2 }, prop: { chakui: 1 } });     /* 部屋の小道具：型の値の選ばれやすさを足す */
```

- 文の決まりは本体と同じ（3 組の専用文・地の文 3 文以上・台詞 3 本・体の語は印・「＠名前＠」）。`steps` の各文は関数 `fn(ctx, a, b, mode)` でもよい。`{a}`＝攻め・`{b}`＝受け。
- 呼ぶ側が `opt.playScene = 'kanbyo-water'` を渡すと、その場面に決める（`when` は見る）。`opt.play = { pos: … }` で型の軸だけ固定することもできる。
- 出来事として一覧に出すため、登録する部屋のファイルに `/* @event … tags=night label=… */` を付ける（8〜25 字の表示名）。きっかけの段は `lead` に書く（`HK.SexLead` の出られない部屋の仕組みとは別）。
