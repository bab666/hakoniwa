# 長いエッチの場面の流れを段階で管理する（設計・2026-11-03）

利用者のフィードバック：`docs/reports/2026-11-03/sex-flow-feedback.md`（同じ台詞・動きの繰り返し／乗ったはずの受けがすぐ真上から押さえつけられる／流れを段階で管理すべき／言葉責めのあとのリアクションが無い）。
追加の指摘：エッチが長すぎる（段数の目安）／夜の主導（誘い受け・襲い受け）の導入が毎回同じ台詞・毎回受けから（「傾向」にする）。

## 1. 原因

長い場面は `HK.ThickSex.scene`（thick-sex.js・小説調）と `HK.ThickEro.scene`（thick-sex-ero.js・男性向け）が本文を組み、その外側を次の包みがそれぞれ独立に段落を差し込んで出来上がる。差し込む側どうしは互いの中身を知らない。

| 包み | 差し込む位置 | 中身 |
|---|---|---|
| attr-r18.js（夜の性格） | 始まりの段のすぐ後ろ ＋ 本体の「感じていく」段の頭（T.scene の ntx） | 攻めの振る舞い＋受けの崩れ方（**同じ表から 2 回引く**） |
| pos-lead-r18.js（夜の主導） | 始まりの段のすぐ後ろ | 受けが誘う・押し倒す・跨る地の文＋受けの台詞（態度ごと **2 本**） |
| ero-initiative-r18.js（能動性の型） | 始まりの後ろ／感じていく段の後ろ／果てる段の前 | 受けの主導・騎乗位などの体位の変化・受けの返し |
| ero-top-lines-r18.js（攻めの台詞） | 始まり・前戯・繋がる・最中・山場・事後 | 言葉責め・焦らしの台詞 |
| ero-play-r18.js・ero-flavor-r18.js ほか | 各段 | 種族のプレイ・夜の色 |

1. **同じ台詞・動きの二度出し**：夜の性格の文（サド：「敷布へ転がし……誰が起きていいって言った？」）を 2 回差し、本体の荒い本番の文（ROUGH_BODY「ベッドへ突き倒し……誰が起きていいって言った？」）とも重なる。`HK.Ero.freshPick` は「同じ文字列」を避けるだけで、「同じ動き・同じ台詞を含む別の文」は避けない。
2. **挿入後の脱がせる**：夜の性格の 2 回目（受けの崩れ方「服をはだけられるたびに腕で体を隠そうと」）が、本体の「感じていく」段（挿入のあと）の頭に入る。
3. **体位が戻る**：能動性の型の騎乗位（受けが上）が「果てる段の前」に入るが、山場の文はその前に選ばれていて、荒い山場「両手首を頭の上で押さえつけたまま、真上から最後の一突き」が残る。
4. **言葉責めのリアクション無し**：攻めの台詞の表（言わせる・声を出させる）と本体の台詞（「顔、伏せるな。ちゃんと声出せ」）のあとに、受けの応答を置く部品が無い。
5. **長すぎる**：本体 6 段＋夜の性格 2＋夜の主導 1＋能動性の型 1〜3＋事後で、段落 15〜21（段にして 13〜17）。
6. **導入が毎回同じ**：夜の主導の台詞が態度ごと 2 本で、設定があれば毎回必ず差していた（新婚部屋で「どうぞ、お好きなようになさってください……」がほぼ毎回）。

## 5. 残り・注意

- 段階・体位は本文の言い回しから読むので、言い回しの拾い漏れ（遠回しな挿入・山場の書き方）はある。新しい長い場面の文を足したら sex-flow-audit を回し、`--why` の例で拾い方（`HK.SexFlow.RE`・`POS`）を足す。

## 6. エッチの型（2026-11-03 追記。設計は play-design.md）

- 包み（`makeWrap`）は、本体の組み立てのあと `F.fix` の前に `HK.Play.apply`（play-r18.js）を呼び、型（入り方・主な責め・道具・体位・終わり方）に沿って前戯・繋がる段・果てる段を置き換え、入り方の段・最中の段・性格が目立つ行為の段を足す。型が組み替えた段は守る段（`info.keep`）として渡す：段数の上限に数えず、外さない（挿入の前へ移すのはよい）。
- 型の体位の段のあと山場までは体位を固定し、別の体位を前提にした言い回し（b）はつなぎの段で戻さずに一文（なければ部品）を外す。点検に (h) 型の矛盾（着衣なのに脱がせる・型の体位のあとに別の体位）を足した（`F.check(units, mode, play)`・`F.analyze(…, play)`。結果の `r.flow.play` に型の印）。
- つなぎ・リアクション・追い上げ・攻めが迫る段の文は、一回の遊びのあいだ使った文を `F.memo.used` で避ける（全部使ったら前に使ったものから戻す）。REACT・BRIDGE・PRESS・BUILD_PRE はどれも 4 本以上（play-more-r18.js）。
- 部屋ごとの専用の長い場面は `HK.Play.addScene(部屋の id, { id, label, when, weight, play, lead, steps: [ { stage: 'undress'|'fore'|'insert'|'play'|'after', … } ], tags })`。段は段階（lead → undress → foreplay → insert → play → climax → after）の順に並べ、きっかけの段（`lead`）を持ち、山場の喘ぎ・終わり方・事後は共通の部品が後ろに付く（play-design.md の 7）。
