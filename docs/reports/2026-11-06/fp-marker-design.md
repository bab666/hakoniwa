# 一人称・二人称の印 `{一人称}`・`{二人称}` と、自然文の置き換えの縮小

2026-11-06。利用者の指摘「住人に一人称を設定すると『冷めないうちに』の『うち』が『俺』に置き換わる」と、要望
(1) 一人称・二人称は自然文を正規表現で探すのではなく、ソースに印を書いて印だけを置き換える方式にする、
(2) 台詞ごとに一人称がブレないようにする、(3) 「うち」の置き換えはもう要らない、への対応。
下調べは担当の棚卸し（置き換えが走る箇所・processText の順番）と実測（誤爆とブレの件数）。

## 1. 決まり（書き方）

| 書くもの | 書き方 | なるもの |
|---|---|---|
| 一人称 | `{一人称}` | 話し手の一人称（住人の設定 → 相手ごとの一人称 → 状況の一人称（怒ったとき・恋人ができてから）→ 口調と性別の既定） |
| 二人称 | `{二人称}` | 話し手の二人称（住人の設定・相手ごとの二人称 → 口調と性別の既定 `HK.toneYou`）。敬語で話す相手への台詞（二人称をそろえない台詞）・二人称が空なら「あなた」 |
| 名前 | `{a}`／`{b}`／`{c}`（書き下ろしの鍵は〈〉） | 今までどおり |
| 体の語 | `{男性器}` `{ナカ}` など（R18） | 今までどおり（lewd-words.js） |
| 話し手の固定 | `「＠{a}＠台詞」` | 今までどおり（voice.js の目印） |

- **新しい台詞は `{一人称}`・`{二人称}` で書く**（3 本の台詞 `「くだけた常体｜硬い常体｜敬語」` でも 1 本の台詞でも同じ）。
  3 本の台詞の例：`「{二人称}がいてくれて、{一人称}はうれしい｜＝｜{二人称}がいてくださって、{一人称}はうれしいです」`。
  3 本で印の数が違ってよい（敬語では一人称を省くなど。base-lint は印の一致を見るとき一人称・二人称の印を外す）。
- **「私」「あなた」の直書きは古い書き方**。当面はこれまでどおり置き換わる（`FP_RE`・`YOU2`）が、新しい台詞には書かない。
  check.js の base-lint が、比べる相手のコミットに無かった 3 本の台詞の直書きを問題にする（既存の行は問題にしない）。
- **書き下ろしの値も印で書く**（tone-fix*・tone-brush*・voice-override*）。鍵は今までどおり「私」「あなた」「〈〉」の本文で書く
  （鍵は元の台詞の本文と同じ形で引くため。印で書いた台詞も、引くときは印を「私」「あなた」に戻した写しで引く）。
- 一人称として「うち」と書きたい台詞（関西弁・ギャルの書き下ろし）は `{一人称}` と書く。「うち」はもう置き換えないので、
  `うち` と書けばいつも「うち」（家・時・所属の「うち」）のまま出る。
- 喘ぎの表には今までどおり一人称・二人称を書かない。喘ぎの言い返し（3 本）に書くときは印で（moan-engine.js の `persons()` が印を展開する）。

## 2. 展開の位置と順番（voice.js の `V.processText`。一つの「」ごと）

| 順 | 処理 | 印の扱い |
|---|---|---|
| 入口 | いちばん外の包み（名前の伏せ字 NameGuard・名前の記号 NameSafe より外） | `{一人称}`→U+E0F1、`{二人称}`→U+E0F2（1 字の印。名前の字が印の字と重なっても壊れない） |
| ⓪ | 心の声（（……）） | 一人称の印があれば話し手を推定して `V.replaceFP`（印 → 一人称）。二人称の印は出口で「あなた」 |
| ① | 目印・話し手の判定（`marked`・`speakerOf`）。話し手が決まらない台詞（区分 u・m）は以下を通らない | 印のまま運ぶ（出口で「私」「あなた」） |
| ③ | 相手ごとの一人称・二人称（fpFor・youFor）を `who.fp`・`who.you` に差し替え | — |
| ④ | 3 本のベースを選ぶ（`HK.Tone.split／pick`。文字列を切るだけなので印は通る。ため口を混ぜる規則の種は印を戻した写しで取る） | — |
| ⑤ | 書き下ろしを引く（`V.overrideFor` の鎖：voice-override・tone-fix・tone-fix-r18・tone-fix-loose・tone-firm） | **鍵は印を「私」「あなた」に戻した写し**（`V.markOut(q)`・`nb.alts` も） |
| ⑥ | **`V.replaceFP`**（書き下ろしの値か本文） | `{一人称}`（値に書いたものも）→ `V.fpFor(who)`。後ろの語を問わず必ず置き換える。どもり（「わ、{一人称}」）は「私」＝「わ」として読み、「ぼ、僕」「お、俺」に。**名詞の引用（区分 c）では印を「私」のまま残す** |
| ⑦⑧ | 辞書（`HK.Tone.apply`・[語彙]）・敬語化・口調の仕上げ（`HK.TONE_FINISH`）・性別の語尾・喘ぎの整え・住人の語尾 | 一人称はもう話し手の一人称になっている（変更なし）。二人称の印は 1 字の私用領域の文字のまま運ぶ（辞書の [語彙] にも仕上げの正規表現にも当たらない） |
| ⑨ | **`V.applyYou`** | U+E0F2・`{二人称}` → 二人称（`youW`）。二人称をそろえない台詞（敬語の相手 kg・名詞の引用・`youW` が空）は「あなた」。どもり（「あ、{二人称}」）は印を戻した元の台詞で判定して `fixYouStutter` |
| ⑪⑫ | 呼び方（`V.applyCalls`・`V.callAddress`） | 二人称はもう語になっているので、今までどおり呼び方に替わる |
| 出口 | いちばん外の包みの出口 | **残った印（1 字の印・`{一人称}`・`{二人称}`）は必ず「私」「あなた」に**（`V.markOut`） |

- processText の外：`V.replaceFP`・`V.applyYou` を直接呼ぶ所（moan-engine.js の `persons()`）も印を展開する（`V.replaceFP` は入口で `V.markIn` を通す。`V.applyYou` は二人称が空でも印を「あなた」に）。
- 記録の外の文（結果の記録・結末・住人の欄のほか）に印が残っていたときの保険：lewd-mark.js の後始末が `V.markOut` を通す（「そこ」にはしない）。
- 関数：`V.MK1`・`V.MK2`（1 字の印）、`V.markIn(s)`（書き方 → 1 字の印）、`V.markOut(s)`（残った印 → 私・あなた）、`V.hasMark(s)`。
- 印の文字：U+E0F1（一人称）・U+E0F2（二人称）・U+E0F3（名詞の引用で一人称の印を一時的に守る）。ほかの印（U+E061・U+E0FE・U+E100〜U+E2FF・U+2060〜U+2064）と重ならない。

### 2-1. 確かめ（段 1。出力が変わらないこと）

  敬語の相手への台詞で「あなた」にならなかった 0、話し手なし・名詞の引用で「私」「あなた」に戻らなかった 0。
  印の文と「私」「あなた」で書いた同じ文の出力は 669／735 で一致（違う 66 は、二人称の印が辞書の [語彙]・仕上げを通らないことと、仕上げのくじの種が文字列で決まることによる語尾の揺れ）。
- check.js：すべて合格。regress は R18版（21 箱庭）・全年齢モード（15）・全年齢版（17）とも全箱庭が一致（印の仕組みを足しただけで出力は変わらない）。

## 3. 自然文の置き換えの縮小（段 2）

| 対象 | 変更 | 理由 |
|---|---|---|
| `FP_RE` の「うち」「ウチ」 | 外した。例外の 3 行（欄が空なら置き換えない・前が「の」か漢字・後ろが へ・一人）も消した | 一人称を設定したときに置き換わった「うち」の 99.1% が一人称でなかった（下の 4） |
| 「私」 | 前が「公・滅・無」（公私・滅私・無私）なら置き換えない | 「公私の区別」→「公俺の区別」。**前が漢字なら一律に外す、とはしなかった**：実測で「全部私のもの」（前が「部」）が一人称として出ており、一律に外すとブレになるため |
| 「わし」 | 前が漢字・カタカナか「ま・か・こ・い」なら置き換えない（交わし・習わし・まわし・かわし・こわし・いわし） | 「言葉を交わし、」→「言葉を交俺、」。**前が文の頭・句読点・空白・かぎかっこだけに絞る、とはしなかった**：のじゃの書き下ろし「賞品はわしがもらう」「それならわしも」の「わし」が置き換わらなくなり、一人称がブレたため（実測で 2 件見つけて直した） |
| 二人称 `YOU2` | 「あなたさま」と「君が代」「君の名は」を変えない | 「あなたさま」→「お前さま」、「君が代」→「お前が代」 |
| 敬語化の `YOU_RE` | 「君が代」「君の名は」を変えない | 同上（敬語化で「あなたが代」にしない） |

ほかの語（俺・僕・あたし・わたし・わたくし…）と、「私」「あなた」の置き換えは今までどおり（古い書き方の台詞が動くように）。
