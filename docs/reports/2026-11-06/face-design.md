# 表情の鍵（HK.Face）の設計（2026-11-06）

CLAUDE.md の「表情の鍵」の項の実装。台詞の一言ずつに表情の鍵を付けられるようにした（画像はまだ持たない。鍵と差し込み口 `data-face` だけで、見た目は変わらない）。下調べは配信の部屋の調査の 9 章。

## 1. 鍵

| 鍵 | 意味 | 印の語 |
| --- | --- | --- |
| normal | 通常 | 〈通常〉 |
| surprise | 驚き | 〈驚き〉 |
| joy | 嬉しい | 〈嬉しい〉 |
| sad | 悲しみ | 〈悲しみ〉 |
| angry | 怒り | 〈怒り〉 |
| shy | 照れ | 〈照れ〉 |
| fear | 恐怖 | 〈恐怖〉 |
| jealous | 嫉妬 | 〈嫉妬〉 |
| smile_lover | 恋人の前の笑顔 | 〈恋人の笑顔〉 |
| smile_family | 家族の前の笑顔 | 〈家族の笑顔〉 |
| moan_1〜moan_4 | 喘ぎ：はじまり・高まり・山場・事後（R18版だけ） | 〈喘ぎ1〉〜〈喘ぎ4〉 |

## 2. 決め方（上から優先。`HK.Face.of(e, k, res)`。k は外側の「」の順の番号）

1. **書いた人の印**：台詞の頭の「〈照れ〉」。`voice.js` の `processText` が、いちばん外側の「」ごとに、「＠名前＠」の前でも後ろでも読んで消す（`HK.Face.read`。頭の `⁠` の印は残す）。〈〉は名前の伏せ字・書き下ろしの鍵にも使うので、**表の語に一致するときだけ**印として扱う。書き下ろしの照合（`overrideFor`）・3 本の台詞の選び分けより前に外すので、印があっても書き下ろしは今までどおり当たる。「」の外や台詞の途中に残った印も消す（`HK.Face.strip`。`processText` の出口と、`voice-seg.js` の仕上げ）。
   - **喘ぎの段**：R18版の `moan-engine.js` が本文へ出した声（`E.moan`・`{m:鍵}`・`HK.Moan.say` の `bare`）の鍵を段に読み替えて覚え（`HK.Moan.faceOf`）、`processText` が台詞の中身で引く。対応：w0・w1・h0・r0・r1・k0・o0・l0・t0〜t2・n0 → moan_1、w2・h1・p0・b0〜b2・r2・l1・t3・n1 → moan_2、w3〜w5・r3・r4・h2・p1・t4〜t6・n2 → moan_3、e0 → moan_4。
   - 指示書の案は「喘ぎの頭に〈喘ぎN〉の印を付けて (1) で読む」だったが、**文に印を入れると途中の処理が変わる**（ero-kit.js の重なりの判定は 6 字以上の台詞だけ・dungeon-lewd.js の使った声の判定は 8 字以上・moan-engine.js の短い声の判定は字数で見るので、5 字の印で判定が変わり、本文が変わって regress が一致しない）。そこで、印は入れずに「出した声 → 段」の表を持つ形にした（同じ声が別の段で出たら後のほう。表は一回の遊び（`HK.simulate` の一回）ごとに空にする：前の回の声が残ると、単独で読んだときと全部読んだときで `e.fc` が食い違った）。書いた人が〈喘ぎ2〉を書いた場合は (1) の印として読む。
2. **出来事の種類**：喘ぎの区分（m）で性的な場面なら moan_2。そのほかは `HK.Face.addTag(名前, 鍵, 欄)` の表（あとに足したものを先に見る）：
   - 札（`e.tag`）：告白→shy・嫉妬→jealous・別れ→sad・恐怖→fear
   - 関係の節目（`e.mark`）：couple・propose→joy、break→sad、cheat・affair→jealous（節目の二人でない話し手だけ。鍵の頭の `!`）
   - 出来事の id（`e.ev`。正規表現）：confess・kokuhaku→shy、jeal→jealous、breakup・…break・mourn・grief→sad、fear・scare・horror→fear
   - 種類：死（`e.kind === 'death'`）→sad、対立（`e.cat === 'conflict'`）→angry
3. **話し手の気分**：`e.md[話し手]`（記録を作った時点の出演者の、平静でない気分。`emotion.js` の `onSay`）。気分 → 鍵：joy→joy、grief→sad、fear→fear、anger→angry、shame・lust→shy。`e.md` の無い記録（保存済み）は `res.history` のその区切りの終わりの 4 つの気分（喜び・悲しみ・恐れ・怒り。35 以上のいちばん高いもの）。区切りの途中の変化と照れは分からない。
4. **上機嫌（joy）なら相手で**：出来事の相手（`e.actors` の話し手でない最初の人）が恋人（結果の組の `label` が lovers など、または関係の欄が lover・married）なら smile_lover、家族（組の `kin`）なら smile_family。結果の組は終わりの関係なので、途中で恋人になった二人は前の場面でも smile_lover になる（表示の目安）。
5. どれも無ければ normal。

話し手が住人でない台詞（モブ・話し手の決まらない台詞）は、印が無ければ null（鍵を付けない）。返す鍵は英小文字・数字・_ の 24 字までだけ（パックの `addTag` の値も同じ。外れたら normal）。

## 3. 記録の欄（新しい記録だけ。保存済みの記録には書き足さない）

| 欄 | 中身 | 作る所 |
| --- | --- | --- |
| `e.fc` | 外側の「」の順の、印・喘ぎの段の鍵の並び（印の無い台詞は null）。印・段のある台詞が一つも無ければ欄を作らない | voice.js（`rec.push` の `fc`）→ voice-seg.js（seg を作ったあと `S.faces`） |
| `e.md` | `{ 住人の番号: 気分 }`（作った時点の出演者の、平静でない気分だけ） | emotion.js の `onSay` |
| `e.ev` | 出来事の id（`ctx._ev.id`。act() から起きた出来事だけ） | engine.js の `say` |
| `e.seg[k].face` | 台詞の区分の鍵（数え上げない属性。保存しない） | voice-seg.js の `S.build`（作るとき）・`S.of`（開き直すとき `e.fc` から） |

保存・履歴は結果の JSON をそのまま置くので、欄が増えるだけ（書き換えない決まりに触れない）。`e.fc`・`e.md`・`e.ev` は本文と結果を変えないので、**regress の指紋からは外した**（regress.js の FP の `JSON.stringify` で、記録の行のこの 3 つの欄だけを落とす。比べる相手のビルドも同じ道具で取るので、足す前のコミットと一致する。一致したことが「足した欄のほかは何も変わっていない」ことの確かめになる）。

## 4. 差し込み口

- 吹き出しの見え方（`V.bubble`）：吹き出し `.bb` ごとに `data-face`、顔のまとまり `.bbg` に最後の吹き出しの `data-face`。
- カードの見え方：台詞の `<span class="q">` に「」の順で `data-face`（入れ子の「」がある文は付けない）。
- 結果カードの住人ごとの気分（emotion.js の `X.html`）・同居生活の結末の顔の `data-face` は今までどおり（7 種の顔の id）。
- 線の見え方・テキスト・画像・PDF には鍵を出さない。

## 5. 全年齢と子どもの姿

- 全年齢版（`HK.SAFE_BUILD`）・全年齢モード（`HK.SAFE_ON`）では moan_* を出さず shy に落とす（`HK.Face.fit`。喘ぎの段を覚えるのも R18 のときだけ）。全年齢版の bundle に「喘ぎ」の語を残さないよう、喘ぎの印の語は正規表現で読む。
- 子どもの姿の判定 `HK.Face.childLook(c)` は口だけ置いた（今は常に偽。登場人物はすべて成人として扱う）。住人の設定に見た目の欄を足すときは、ここで読んで moan_* を shy に落とす。

## 6. 計測（作業用の試し。`futari`・`whiteroom`・`locker`、2 人、恋人、シード 4242）

- 試しに印つきの台詞を差した記録で、印の消し残り 0、`e.fc` に shy・surprise が入り、保存（JSON を通す）して開き直しても鍵が同じ（全記録で一致）。
- 喘ぎの段：同居生活で moan_1・moan_2・moan_3、媚薬ロッカーで moan_3 が付いた。全年齢版では moan_* は 0。
