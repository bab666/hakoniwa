# 女性の台詞の「女言葉と命令形の混在」：判定・直し・件数（2026-11-06）

配信の通し読み（`haishin-playtest.md` の 21・「直せなかったもの（本体側）」の 1 行目）で、強気（proud）の女性の台詞が
「責めるだけで終わりなの？　……ちゃんと責任をとれ」のように、女性的な語尾の文と命令形の文を一つの台詞に並べていた。本体の口調の仕上げの直し。

## 1. 原因

女性の話し手の台詞は、最後に性別の語尾の仕上げ（`js/tone-plus.js` の `V.genderEnd`）を通る。その中の 3 つの部品が**文ごとに**語尾を女性の言い方にする。

| 部品 | 中身 | 命令形を残す場合 |
| --- | --- | --- |
| `femSoft` | 「ぜ・ぞ」→「よ」、「だろ」→「でしょ」、「おい」→「ねえ」、「〜しろ」→「〜しなさい」 | 漢字＋しろ 以外の命令 |
| `femKiri` | 文末の命令・禁止・詠嘆の「な」・「〜てくれ」・「〜のか」を「〜なさい」「〜ないで」「〜ね」「〜の？」に（強気・意地っ張りは「〜なさい」、ほかは「〜て」） | とっさの「伏せろ！」（！の命令）・脅し・拒みの「触るな」・表に無い動詞（とれ）・**文の途中の命令（答えろ、）** |
| `femProud`（強気だけ） | 「〜だ」→「〜よ」、「何だ」→「何なの」、「〜か。」→「〜なの？」、「だが」→「だけど」 など（2026-10-29 の利用者の報告「強気の女性が厳格のような言い方になる」で足したもの） | 命令はさわらない |

残す場合の命令形と、ほかの文の女性語が同じ台詞に並ぶと混在になる（「何なの？　答えろ、暇なんだから」「脱ぎなさい。……さっさとしろ」「あと三回よ！　頑張れ！」）。
また、硬い言い切りの口調（厳格・冷静・冷静（落ち着き）・冷静（丸い）。`FEM_PLAIN`）の女性の「〜だぜ」「〜ぜ」は、言い切り（「〜だ」）にするつもりの直しより先に「〜だよ」「〜よ」にする行があり、厳格・冷静の女性に「よ」が付いていた。

## 2. 直し（`js/tone-plus.js`。両ビルド）

- **台詞単位で揃える**：`V.genderEnd` は、いつもどおり仕上げたあとの台詞に `V.femCmdMix`（命令形の句が残り、女性的な語尾の文もある）が当たれば、その台詞を**女性的な語尾を足さない仕上げ**でやり直す。
  やり直しは、厳格・冷静の女性と同じ言い切りの仕上げ（荒い語の「ぜ」「やがれ」「じゃねえ」「ねえ（否定）」だけ直し、命令・言い切りはそのまま。`femProud`・`femKiri` の文末の書き換え・「しろ」→「しなさい」は当てない）。
  「だろ」→「でしょ」・「おい」→「ねえ」は女性語の語尾ではないので、やり直しでも直す（強気の女性の「おい」は tone-feel の TD の判定に当たる）。
- **強い口調の「ぜ」**：硬い言い切りの口調とやり直しの台詞は、「〜だぜ」「〜ぜ」を先に言い切りにする（「待て、それは俺のだぜ」→ 厳格の女性「待て、それは俺のだ」。前は「だよ」）。
- 命令形の残らない台詞（強気の女性の「ここにいなさい。……命令よ」「言っておくけど、これきりよ」「中身は、絶対に秘密よ」）は今までどおり。2026-10-29 の利用者の決まり（強気の女性は「〜なさい」「〜よ」で話す。CHANGELOG「強気の女性の台詞が厳格のような言い方になる件」）を変えないため、強気の女性の女性語そのものは外していない。
  配信の報告のもう一つの例「日記をつけることよ。中身は、絶対に秘密よ」は、この決まりどおりの言い方なのでそのまま（外すなら利用者の判断が要る）。
- 判定の語の並び（女性的な語尾・命令形）は、本体の `V.femCmdMix` と点検の `feel/tr.js` で同じものを持つ。
  - 女性的な語尾の文：文末が 〜わよ・〜わね・〜のよ・〜かしら・〜だわ・〜なのね・〜なのよ・〜なの・名詞＋よ（こと・もの・はず・好み など）・〜るわ／〜ないわ・〜なさい
  - 命令形の句（句点・読点・？・！・……で区切った句の終わり）：〜しろ・〜せよ・〜やがれ・え段＋ろ（〜てろ・やめろ・見せろ・答えろ）・見ろ／寝ろ・五段の命令（取れ・とれ・言え・待て・黙れ・帰れ・脱げ・頑張れ・覚えろ など）・来い・〜するな／触るな／動くな など。「ところ」「こころ」「うしろ」は除く
